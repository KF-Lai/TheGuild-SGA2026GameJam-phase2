# 隊伍派遣系統 — 遊戲設計文件

**版本**：1.0  
**日期**：2026-04-08  
**設計師**：系統設計師  
**狀態**：實裝就緒

---

## 概覽

玩家可組織 1–4 人公會成員組隊接取任務。隊伍組成可解鎖協力加成，影響成功率，並引入失敗風險（成員陣亡）。獎勵均分隊伍成員，創造風險/回報權衡：大隊伍更安全但每人獲益更少。

---

## 隊伍組織規則

### 隊伍人數限制

隊伍人數受限於**任務難度**和**公會等級**（取較低者）：

| 任務難度 | 最小 | 最大 |
|---------|------|------|
| F, E    | 1    | 1    |
| D, C    | 1    | 2    |
| B, A    | 1    | 3    |
| S, SS, SSS | 1 | 4    |

| 公會等級 | 最大隊伍人數 |
|---------|-------------|
| 1       | 1           |
| 2       | 2           |
| 3       | 3           |
| 4+      | 4           |

**限制**：`實際最大隊伍人數 = min(難度上限, 公會等級上限)`

## 協力系統

### 協力加成（無懲罰）

當隊伍包含指定職業對時，加成生效：

| 協力對 | 加成效果 |
|--------|---------|
| 戰士 + 療癒師 | 成功率 +15% |
| 斥候 + 遊俠 | 獎勵金幣 +20% |
| 法師 + 任何職業 | 成功率 +10%（對討伐任務） |
| 守護者 + 任何職業 | 死亡機率 -10% |

**應用**：
- 若滿足多個協力對，加成堆疊
- 守護者加成僅在發生死亡時適用（見死亡規則）
- 法師加成僅對討伐（戰鬥）任務適用

## 成功率計算

**公式**：

```
基礎成功率 = 加權平均(成員成功率)

加權平均 = (0.50 × 最高率) + (0.50 × 其他平均)
```

**流程**：
1. 找出成功率最高的成員
2. 給該成員 50% 權重
3. 計算其他成員的成功率平均值
4. 給平均值 50% 權重
5. 合併：`最終率 = (0.50 × 最高) + (0.50 × 其他平均)`
6. 應用協力加成（加法）
7. 限制在 [0.0, 1.0]

**範例**：
- 隊伍：戰士（80%）、盜賊（60%）、療癒師（70%）
- 最高：80%（0.50 × 0.80 = 0.40）
- 其他平均：(60% + 70%) / 2 = 65%（0.50 × 0.65 = 0.325）
- 基礎：0.40 + 0.325 = 72.5%
- 若有戰士 + 療癒師：+15% → 87.5%

## 失敗與陣亡規則

**任務失敗時**（成功率判定失敗）：

- **隨機一名隊伍成員陣亡**（不是全員）
- 死亡率：`基礎死亡機率 = 隊伍中每名成員 5%`
  - 範例：2 人隊伍 = 5% 機率有一人陣亡（若任務失敗）
- 守護者協力降低死亡機率：`死亡機率 × 0.90`
- 陣亡成員需復活（金幣費用，透過公會大廳 UI，待定）

## 獎勵分配

### 基礎獎勵分割

```
每人獲得獎勵 = 基礎獎勵 / 隊伍人數
```

**流程**：
1. 任務成功獲得 `基礎獎勵`（由難度/類型決定）
2. 每名隊伍成員獲得 `基礎獎勵 / 隊伍人數`
3. 斥候 + 遊俠協力：獎勵 × 1.20

**範例**：
- 任務：B 級難度，300 金幣基礎獎勵
- 隊伍：3 人
- 每人：300 / 3 = 100 金幣
- 若有斥候 + 遊俠：100 × 1.20 = 每人 120 金幣

**風險/回報權衡**：
- 單人任務：獲得 100% 基礎獎勵，但失敗風險高
- 滿人隊伍：失敗風險低，但每人只獲 25–33% 獎勵
- 玩家須根據成員信心和目標（速度 vs. 報酬）選擇

## 派遣記錄結構

```typescript
interface PartyMember {
  member_id: string;
  name: string;
  archetype: string; // 戰士、療癒師、斥候、遊俠、法師、守護者
  success_rate: number; // [0.0, 1.0]
}

interface DispatchRecord {
  dispatch_id: string;
  mission_id: string;
  party: PartyMember[]; // 長度 1–4
  dispatched_at: Date;
  
  // 派遣時計算
  base_success_rate: number;
  synergy_bonuses: string[]; // 生效協力名單
  final_success_rate: number; // 協力加成後
  
  // 完成時
  succeeded: boolean;
  member_died?: string; // 陣亡成員 ID；無則 null
  reward_per_member: number;
  completed_at: Date;
}
```

## UI 流程

1. **隊伍選擇畫面**： 
   - 顯示任務詳情（難度、類型、基礎獎勵）
   - 顯示可用成員（等級、職業、成功率）
   - 強制隊伍人數限制
   - 即時顯示生效協力

2. **派遣前總結**：
   - 最終成功率（含協力加成）
   - 預期每人獎勵
   - 失敗時的潛在死亡風險
   - 確認或取消

3. **派遣確認**：
   - 鎖定隊伍，開始計時/結算

4. **任務完成**：
   - 顯示成敗、獎勵、任何陣亡
   - 若適用，提供復活 UI
