# GDD：冒險者成長系統

**系統**：進度、精通  
**範圍**：每個冒險者的階級、XP、特性、死亡率縮放

---

## 1. 階級系統（E → D → C → B → A → S）

**進度模型**：線性 XP 累積，經驗値閾值呈指數增長。

| 階級晉升 | XP 門檻 | 死亡率修正  | 解鎖特性 |
| -------- | ------- | ----------- | -------- |
| 初始 → E | —       | +30% (100%) | 特性 #1  |
| E → D    | 100     | +28% (98%)  | —        |
| D → C    | 150     | +26% (96%)  | 特性 #2  |
| C → B    | 225     | +24% (94%)  | —        |
| B → A    | 340     | +22% (92%)  | 特性 #3  |
| A → S    | 500     | +20% (90%)  | —        |

**死亡率修正**：每晉升一階降低基礎死亡率 2%（累積）。最低限制：5%。

- 階級 E：基礎死亡率 × 1.30
- 階級 D：基礎死亡率 × 1.28
- 階級 C：基礎死亡率 × 1.26
- 階級 B：基礎死亡率 × 1.24
- 階級 A：基礎死亡率 × 1.22
- 階級 S：基礎死亡率 × 1.20

## 2. XP 獲得

冒險者根據任務結果獲得 XP：

| 結果 | XP 獎勵 |
| ---- | ------- |
| 成功 | +15     |
| 慘勝 | +12     |
| 失敗 | +8      |
| 陣亡 | 0       |

**進度範例**：

- 新手冒險者完成 7 次成功（105 XP）→ 解鎖 E 階
- 再完成 6 次成功（90 XP）→ 達成 D 階（累計 195 XP）
- 稍後完成 D → C 需 100 XP（共 295 XP）→ 達成 C 階，解鎖特性 #2

## 3. 特性系統

**資料結構**：

```
特性 {
  特性 ID：字串           // 例：「戰士-鐵皮」
  名稱：字串              // 例：「鐵皮」
  效果：物件              // { 類型、大小 }
}
```

**解鎖規則**：

- 特性 #1 在 E 階解鎖
- 特性 #2 在 C 階解鎖
- 特性 #3 在 A 階解鎖
- 特性是**職業專屬**
- 所有已解鎖特性保持生效（被動加成）

### 各職業特性範例

**戰士**

- E 階：「鐵皮」→ 防禦 +1
- C 階：「復仇」→ 受傷後下回合傷害 +20%
- A 階：「堅不可摧」→ 所有傷害減少 1（最低 1）

**盜賊**

- E 階：「疾速斬」→ 攻擊 +1
- C 階：「暗影步」→ 躲避攻擊機率 +20%
- A 階：「死亡標記」→ 標記敵人傷害 +3

**法師**

- E 階：「咒術精通」→ 魔法攻擊 +1
- C 階：「魔法盾」→ 生命值 < 50% 時，防禦 +2
- A 階：「祕法精通」→ 法術消耗降 1（最低 1）

**聖職者**

- E 階：「聖光」→ 治療 +1
- C 階：「神聖守護」→ 治療的盟友獲得防禦 +1（到下回合）
- A 階：「救贖」→ 當盟友瀕死時，治療至 30% 生命（每戰鬥一次）

## 5. 平衡備註

- **門檻間距**（100 → 150 → 225 → 340 → 500）鼓勵早期參與；後期進度自然放緩
- **死亡懲罰**（0 XP）製造緊張感；失敗/慘勝仍有努力獎勵
- **每階 2% 死亡率降低**讓風險更有意義，但永遠不會微不足道（最低 5%）
- **特性解鎖門檻**（E、C、A 階）確保中期精通感覺是贏得的

---

## 6. 未來調整參數

- XP 獎勵：若晉升速度不當，調整成功/慘勝/失敗倍數
- 門檻：若早期階級過快或後期過磨人，上下調 ±20%
- 死亡率最低限：若 S 階冒險者輕易通關，提高至 10%
- 特性效果：按職業平衡每個專業的力量預算（cf. 特性-平衡矩陣.md）
