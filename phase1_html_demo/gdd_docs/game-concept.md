# Game Concept — The Guild

> **文件狀態**：已設計
> **最後更新**：2026-04-06

## 簡介

**The Guild** 是一款放置型公會經營遊戲。玩家作為公會長有以下的核心操作：
1. 招募冒險者
2. 審核委託
3. 推薦冒險者委託，以此培養冒險者（冒險者有可能會拒絕你推薦的委託，並且冒險者也會自行接取委託）
4. 建設公會
5. 根據玩家招募了哪種冒險者、接受了什麼委託，來推進城鎮發展與選擇陣營

每日遊玩時間目標 ≤ 30 分鐘，適合碎片化時間。

## 平台與技術

- **平台**：H5 瀏覽器（TypeScript + Vite）
- **UI 風格**：MUD 風格文字輸出 + 簡單 DOM UI
- **存檔**：localStorage（無後端）
- **截止日**：2026-04-10（Gamejam）

## 核心循環

```
接受委託（任務出現）
    ↓
招募冒險者（候選池刷新）
    ↓
派遣任務（玩家推薦 → NPC 決定接單）
    ↓
等待（實時計時）
    ↓
任務結算（成敗 + 死亡判定）
    ↓
收取傭金 / 承擔賠償
    ↓
（回到頂部）
```

## 設計支柱

1. **離線 / 長期經營感**：玩家可以離開，回來看結果
2. **NPC 有自主性**：冒險者不是工具，會拒絕任務
3. **決策有真實後果**：死亡是永久的，金幣有限，聲望影響未來

## 核心參數


| 維度    | 範圍                        |
| ----- | ------------------------- |
| 冒險者階級 | F、E、D、C、B、A、S（7 階）        |
| 任務難度  | F、E、D、C、B、A、S、SS、SSS（9 階） |
| 世界危險度 | E、D、C、B、A（5 階）            |
| 任務類型  | 討伐、護送、採集、調查               |
| 資源    | 金幣（非負整數）、聲望（-100 ~ 100）   |


## 資源說明

- **金幣**：用於邀請老手冒險者與公會建設，成功任務獲得傭金
- **聲望**：公會在城市的名聲，影響高難度任務出現機率，以文字標籤顯示（非數字）
