## 0. 全域規格

所有資產依類型統一規格，**同類型使用相同畫布尺寸**。

| 類型 | 畫布尺寸 | 格式 | 透明背景 |
|---|---|---|---|
| 角色立繪（Character Sprite） | 512 × 768 px | PNG | 是 |
| 場景道具（Prop） | 512 × 512 px | PNG | 是 (\*D-3 委託板例外：1024 × 768 px) |
| 紙條（Paper Note） | 512 × 768 px | PNG | 是 |
| 背景圖（Background） | 1920 × 1080 px | PNG | 否（實色背景） |
| UI 圖示（Icon） | 256 × 256 px | PNG | 是 |

**通用提示詞規則（GPT 生成時附加，自然語言敘述優先；下列短語可作為英文關鍵字補充）：**
- Chibi anime character illustration with western dark fantasy worn texture, around 3 to 3.5 head body proportion
- Clean crisp black lineart with thicker outer contour and thinner inner structure lines; no hand-drawn jitter, no rough ink-sketch feel
- Flat color blocks with a single hard-edged shadow layer; zero gradients, zero airbrush, no soft glow
- Localized hand-painted grime, torn cloth edges, bandage accents — decorative, never overrides the line silhouette
- Muted warm palette (worn brown, burnt sienna, ink black, dusty off-white); 5–8 colors total per character
- Consistent upper-left soft lighting; clean isolated subject on transparent background（背景圖除外）
- No text, no watermarks, no smooth gradients in color fills

> **風格分層規則：** 角色精靈（Character Sprite）、道具（Prop）、UI 圖示（Icon）一律採「**日式 chibi 動漫 + 西式黑暗奇幻舊化質感**」的混合風（乾淨線稿 + 平塗 + 硬邊陰影 + 局部手繪髒舊紋理）；背景（Background）採繪畫式插畫（painterly illustrated）風格，兩層形成有意識的風格分層，無需統一。

## 0.1 角色美術風格基準（Character Style Benchmark）

**視覺基準圖：** `design/DesignFiles/Art/角色參考圖.png`

> **此圖只是「畫風的觀賞感受」基準，不是「人物本身」基準。**
> 它定義角色立繪的：風格、頭身、線條、上色感受、細節密度。
> 它不定義：要繪製什麼造型的角色。
>
> **明確規則：基準圖中的兜帽收割者形象（兜帽斗篷、鐮刀、眼罩、護身符等）一律不可照搬。**
> 各角色的服裝、髮型、配件、武器、表情、姿勢，全部以本文件 §1 各角色描述為準。
> 基準圖只負責回答「畫起來看起來像什麼質感」，不負責回答「畫的是誰」。

所有角色立繪（包括奧菲莉雅、職員、具名／通用冒險者）一律採用此基準。下方第 1 章的角色外觀描述屬於「敘事意象」（narrative cues），需在以下風格框架內表達。

### 0.1.1 整體風格定位（用一句話描述）

> 「乍看是 3 頭身上下、輪廓乾淨的日式 chibi 動漫角色；走近一看，會發現布料邊緣有撕裂、繃帶層疊、布料髒舊污漬等手繪感舊化紋理，色調是低飽和的暖棕、焦褐與墨黑——是一個經歷過長途奔波、但依然站得很穩的小角色。」

風格組成可拆為兩層：

- **第一印象層（日式 chibi 動漫）**：3~3.5 頭身的小巧角色，頭大身小但比例自然，五官清楚但不誇張；輪廓乾淨銳利，色塊大膽簡單，乍看是日系 Q 版。
- **質感層（西式黑暗奇幻舊化）**：服裝邊緣有撕裂、繃帶層疊、布料髒舊污漬；色調偏低飽和的暖棕／焦褐／墨黑；散發出「使用過、走過長路」的氛圍，與純粹可愛系 chibi 區隔。

整體目標：在 Q 版可愛比例的親切感中，藏入足夠的舊化紋理與細節，讓玩家相信角色背後有故事，而不是萌系吉祥物。

### 0.1.2 人物結構與頭身

| 項目 | 規格（以基準圖視覺感為準） |
|---|---|
| 頭身比例 | **約 3~3.5 頭身**，頭部佔整體高度約 28~33% |
| 頭部 | 偏圓潤但下巴仍可辨識；五官（眼、眉、口）清楚但不誇張，眼睛中等大小（非巨眼系，也非極簡點狀） |
| 軀幹 | 短小敦實，不追求修長身材；可呈現基本性別輪廓但極度簡化 |
| 四肢 | 手腳以線稿輪廓 + 平塗呈現，手部不要求精細手指；靴子、鞋子有清晰結構 |
| 種族差異 | 全種族統一頭身基準；差異以身形寬窄、髮型、配件區分（矮人較矮壯、精靈纖細） |

### 0.1.3 線條

| 項目 | 描述 |
|---|---|
| 線稿性質 | **乾淨清晰的黑色描邊**；不要手繪粗糙抖動感、也不要西式墨線速寫感 |
| 外輪廓 | 較粗（2~3px 等效），銳利清楚 |
| 內部結構線 | 較細（1~2px 等效），用於分隔身體部位、衣物層次、配件邊界 |
| 線條質感 | 邊緣銳利、無羽化、無模糊；轉角清晰；允許在頭髮、布料毛邊處出現自然分岔的尖角 |

### 0.1.4 上色感受

| 項目 | 描述 |
|---|---|
| 著色方式 | 大面積**平塗（flat color）** + **1 層硬邊陰影色塊**；不使用漸層、不使用羽化，所有色塊邊界清楚 |
| 光源 | 統一從畫面左上斜射，陰影落在右下方 |
| 髒舊紋理 | 在布料邊緣、繃帶、磨損處可加入**手繪感的不規則暗斑或細小色塊**，模擬污漬、塵土、磨痕；但主體形狀必須仍由線稿主導，紋理只是裝飾 |
| 色板 | 極度精簡，**整體 5~8 色**含陰影色；以低～中等飽和度的暖棕、焦褐、墨黑、米白為主；只在關鍵敘事細節（如血跡、聖徽、茶湯）才使用點綴亮色 |
| 整體氛圍 | 暖調但壓抑，不亮麗鮮豔；近似基準圖的色溫與氣質 |

### 0.1.5 細節程度

- **保留**：服裝結構（領口、腰帶、護肩、靴帶）、必要配件（木酒杯／陶瓷茶杯、聖徽、繃帶）、舊化痕跡（破爛下擺、布料污漬）、髮型大致層次
- **簡化**：手指細節、繡花刺繡、布料褶皺紋理、髮絲分股、紐扣縫線
- **避免**：寫實布料光影、毛髮逐根渲染、漸層膚色過渡、3D 質感反光、外部光暈／散景
- 整體細節密度比照基準圖：**結構清楚但不堆砌**，髒舊感由幾處有意的線條／色塊裝飾提供，而非鋪滿整個畫面

### 0.1.6 視角、姿勢、構圖

- **視角**：正面或 ¾ 側面（偏左約 15°），與基準圖一致
- **姿勢**：全身站姿，雙腳落地，重心略偏一側，無誇張動作
- **視線**：略微抬頭看向鏡頭，使眼神可被辨識
- **構圖**：角色居中，腳底距畫布底部留約 64px 安全區（後續可疊地面陰影）

### 0.1.7 畫布與輸出

| 項目 | 規格 |
|---|---|
| 角色立繪畫布 | **512 × 768 px**（縱向 1:1.5），透明背景 PNG |
| 輸出 | 線稿邊緣銳利，平塗區無漸層；不可有外部光暈、模糊散景 |
| 背景 | 透明（基準圖的綠色純底僅為輸出參考，最終資產一律去背） |
| 邊界 | 角色不超出畫布；上下左右各保留 ≥16px 透明邊界 |
| 變體一致性 | 同角色不同變體（受傷／坐姿等）必須沿用同一頭身、同一臉部比例、同一線稿風格與配色 |

### 0.1.8 一致性檢查清單

每張角色出圖完成後，逐項確認：

- [ ] 頭身比例落在 3~3.5 頭，頭大身小但比例自然
- [ ] 線稿乾淨銳利，外輪廓明顯粗於內部線條，無手繪抖動或墨線速寫感
- [ ] 上色為平塗 + 硬邊陰影，完全無漸層
- [ ] 出現適度髒舊紋理（布料邊緣污漬、撕裂、繃帶等），但不蓋過主體輪廓
- [ ] 整體色板 ≤8 色，暖棕／焦褐／墨黑為基調，與基準圖色溫一致
- [ ] 視角為正面或 ¾ 側面，全身站姿
- [ ] 透明背景乾淨，無殘留底色或雜點
- [ ] 與同角色其他變體可疊圖比對，五官位置、身高、線稿風格一致
- [ ] **未照搬基準圖中的兜帽、鐮刀、眼罩、護身符等收割者特徵**（人物造型一律以 §1 描述為準）
