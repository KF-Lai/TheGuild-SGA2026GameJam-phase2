## 2. 紙條視覺與文字內容（FB-S1 / FB-S2）

### 紙條金句

# 文字：鏡中無月。第七位請小心。

### 紙條視覺規格

# 美術：三版視覺差異明顯（規格基準見 GDD-FSD-patch v3.1 §5）

**light 版**
- 紙質：米白偏奶油色，無明顯紋理，輕微羊皮感
- 字色：深棕墨水（#3B2A1A ~ #2C1A0A）
- 行距 / 字距：1.6× 寬鬆，靠左對齊
- 紙緣：整齊，四角輕微缺損 1-2px
- 落款：極小晨曦聖徽（4×4px，亮度低，視覺謙卑）

**dark 版**
- 紙質：灰黃色，紙漿雜質感（顆粒噪點 3-5%）
- 字色：近純黑（#1A1A1A ~ #0D0D0D），字跡微顫抖 ±1-2px
- 行距 / 字距：1.2× 壓縮，基線傾斜 1-2°
- 紙緣：不規則撕裂（上緣或左緣）+ 右下焦痕
- 落款：扭曲線條符號（不規則橢圓加十字）

**neutral 版**
- 紙質：米白接近標準白，輕微泛黃
- 字色：深灰（#2E2E2E ~ #222222）
- 行距 / 字距：1.4× 正常
- 紙緣：輕微折痕，對稱磨損
- 落款：無落款或單一破折號「—」

### 紙條呈現動畫

# 動畫：紙條進入方式（與 Stage 1 同）——輕微顫抖，短暫光暈（2 秒內消散）；根據 styleTag，光暈色調會微調（light 偏白金，dark 偏紫紅）

## 4. 劇情委託內容（categoryID=3）

### 委託名稱

# 文字：前往北方廢墟尋找消失的學者

### 委託描述

# 文字：一位學者失蹤了。他最後被看見是在北方廢墟進行某項研究。派出去的人應該找到他——或者他留下的東西。廢墟內有異常現象，但具體是什麼沒人說清。這是 B 級難度的調查任務。如果派出的不是正確的人，他們可能也回不來。

### 委託難度與機制

- difficulty: B
- typeID: 4（調查）
- factionID: 1
- isScriptedDeath: 0
- requiredTraitID: 0

### 結算 Epilogue 文本

#### 成功（如果可成功）

- light 偏好：# 文字：冒險者帶回了學者的最後手稿。上面記錄了「女神之痕」的觀察——聖殿在某個時刻曾驅逐過某種東西。聖殿有秘密。
- dark 偏好：# 文字：冒險者帶回了學者的衣物。但學者本人不見了。衣物上有契者的符號——他們在那裡。
- mixed/neutral：# 文字：冒險者帶回了一張寫了一半的便條。內容看不懂，像是被急忙中斷的研究記錄。

#### 失敗 / 死亡

- light 偏好：# 文字：冒險者沒回來。但學者的手稿被送回了公會——有人確保它被送到了正確的地方。
- dark 偏好：# 文字：冒險者失蹤。廢墟沒有再傳來任何消息。只有風吹過石堆的聲音。
- mixed/neutral：# 文字：冒險者的屍體未尋獲。廢墟吞掉了他和他要找的人。

#### 特殊事件 - 如果奧菲莉雅推薦的冒險者死亡

# 機制：結算後，夜間事件觸發——奧菲莉雅在公會角落坐了一整晚。她不哭，不說話。她就是坐著。清晨時，她回到椅子上，神情未變。

# 美術：夜間場景的光線變為月光色；奧菲莉雅在不同角落的椅子上，背向玩家，肩膀沒有抽動——純粹的靜止與陪伴。公會誌物件在她身旁，但她沒翻。
