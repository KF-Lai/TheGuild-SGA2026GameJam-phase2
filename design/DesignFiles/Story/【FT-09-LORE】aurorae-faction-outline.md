## 1. 核心敘事策略

### 1.1 三大設計地基

| 地基 | 內容 | 解決的問題 |
|---|---|---|
| **情感錨點：奧菲莉雅** | 一位從第一天就在公會、會死、不被神話加持的傭兵 | 給玩家一個可以愛上的具體對象 |
| **異神朦朧化** | 所有可見現象歸因於**契者**（具體的人）的行為，異神本身**全程不顯現、不命名、不解釋** | 異神既是未知力量也不過度具象，符合「3 分鐘 session 撐不起抽象克蘇魯」的限制 |
| **公會誌真相** | 公會誌是**奧菲莉雅自己想寫的東西**——沒有傳承、沒有任命，她從前任公會長遺留的斷簡殘篇拼湊出歷代故事，她只是個喜歡記錄的人 | 取代廉價的輪迴設定，建立謙卑的歷史感（v3.1 修正） |

### 1.2 敘事結構

| 區段 | 階段 | dangerLevel | 通用 / 分軌狀態 |
|---|---|---|---|
| **序章** | Onboarding | — | 完全通用 |
| **前期** | Stage 1 / Stage 2 | E 和平 / D 動盪 | 主軌通用、輔軌微差 |
| **轉折點** | Stage 3 | C 暗湧 | 主軌**形象與口吻分軌**、內容相同 |
| **後期** | Stage 4 / Stage 5 | B 危局 / A 末世 | 主軌**詮釋分軌**、內容相同；Stage 5 含奧菲莉雅死/活分支 |

> Jam 版實作策略：FT-09 機制上仍是單路線（不違反 GDD §1）；分軌透過文本變體實作，劇情階段本身不分支。

### 1.3 取消的舊設計（保留紀錄供 audit）

| 取消項 | 取消原因 |
|---|---|
| 玩家 = 第十一任公會長（輪迴設定） | 廉價、老土、與 Soulslike 過於相似 |
| 倒扣相框揭露玩家臉 | 同上 |
| 「葉、鏡、席、凡」前任公會長名字輪替 | 同上 |
| 載體 A 異神村莊「莊稼長得好」「孩童不哭」 | 把異神力量過度具象化（朦朧化方向）；「孩童」涉及擴展版紅線 |
| 「祭司長眼神不對」「祭司長動搖」戲劇性對抗 | 太明示、破壞女神隱晦陰影的鋪陳 |
| **歷代記錄者傳承**（v3.1 取消） | 比輪迴更需要解釋——誰在安排「公會長身邊永遠有記錄者」？改為「奧菲莉雅自己想寫」 |

### 1.4 女神 vs 奧菲莉雅角色定位（v3.1 新增）

> **本劇本以「玩家偏向 light → 累積女神陣營分數 → 解鎖 Stage」為機制路徑，但 Stage 內容的敘事中心是奧菲莉雅與公會誌，女神是「環境」而非「主角」。**

| 角色 | 出現方式 | 敘事位置 |
|---|---|---|
| **奧菲莉雅** | 每個 Stage 都是核心；持續視覺存在 | **前景主角** |
| **公會誌、椅子、茶** | 持續視覺存在 | **前景物件** |
| **女神** | 透過神諭、聖徽、選定者體系**間接出現** | **環境** |
| **異神 / 契者** | 透過冒險者口述、紙條**間接出現** | **環境** |

呼應遊戲核心幻想（你不是英雄，**讓英雄誕生或殞落的人**）——女神也不是「為玩家服務的英雄」。玩家透過**更具體的存在**（奧菲莉雅）去感受**更抽象的存在**（女神）。

> **避免後續開發者誤解**：本劇本不是「女神主角劇」，是「**玩家偏向女神陣營後，世界透過奧菲莉雅與公會誌如何回應玩家**」的劇本。

## 2. 情感錨點：奧菲莉雅

### 2.1 角色基礎設定

| 面向 | 內容 |
|---|---|
| **姓名** | 奧菲莉雅（Ophelia） |
| **職業** | 傭兵（C-03 professionID=7，中性安全牌） |
| **種族** | 人類（C-04 raceID=1） |
| **階級** | E 階（與遊戲開局公會 Lv1 對應；不晉升） |
| **特質** | 「沉默」（trait，需新增於 TraitTable，見 §10.4 機制需求） |
| **isUnique** | 1（全局唯一，AdventurerTemplate 已支援） |
| **factionID** | 0（neutral，**重要**——她不屬於女神陣營） |
| **來歷** | 不是被玩家招募的；遊戲開始時**已在公會**（前任公會長留下的最後一位冒險者） |

### 2.2 設計原則

- **她不是 NPC 對白機器**：5 個 Stage 加起來台詞不超過 10 句
- **她沒有特殊身份**：不是預言中的人、不是被選定者、不是任何陣營的眼線
- **她會死**：機制上死亡風險與其他冒險者相同；玩家可以選擇派她或不派她
- **她的力量來自視覺定位**：總是坐在公會某張椅子上，每天都在那裡——這個**持續的視覺存在**才是她的記憶點來源
- **她是「擁有過去」的人**（v3.1 新增）：她不公開講述，但透過微小細節（口袋裡的舊紙條、看紙條時的猶豫）暗示她有「**讓她可能想要平靜**」的過去——這是 Stage 4「我懂他們」台詞的著力點

### 2.3 Onboarding 開場場景（v3.1 強化）

玩家第一次進入遊戲，公會場景空蕩、灰塵覆蓋、前任的書桌未整理。

角落的椅子上，奧菲莉雅坐著。她抬頭。

> **「你來了。我等了一個月。」**

她把茶倒給玩家。

> **「桌上的事，由你決定。地上的事，我們一起。」**

接著進入 Tutorial 流程。

**這 30 字以內的開場做了什麼**：

| 設計元素 | 效果 |
|---|---|
| **椅子的視覺定位** | 日後 Stage 4「茶冷了」的伏筆地基 |
| 「**我等了一個月**」 | 暗示前任離開了一個月。前任不需要被命名，存在感建立 |
| 「**桌上的事，由你決定。地上的事，我們一起。**」 | 對應遊戲機制（玩家審核委託 = 桌上；冒險者出去 = 地上）；同時建立奧菲莉雅作為「**會下場的人**」的基調 |

### 2.4 她的弧線（情感鋪陳骨架）

| Stage | 動作（極短） | 玩家感受層級 |
|---|---|---|
| Onboarding | 等了玩家一個月，倒茶。「桌上的事，由你決定。地上的事，我們一起。」 | 同事 |
| Stage 1 | 第一張紙條出現。她看那張紙條**比平常久一點**，皺眉。「我去吧。」回來。沒受傷。**她沒解釋為什麼皺眉**。 | 「她有反應」 |
| Stage 2 | 三封信到達。她看了三封信，**對其中一封微微點頭**。然後從口袋裡拿出**一張自己的舊紙條**，看了一眼，收回去了。**不解釋**。 | 「她在判斷」 |
| Stage 3 | 「鏡中無月」紙條到達。她**第一次拒絕**：「不該是我去。」推薦別人去。如果那個人死了，她在角落坐了一整晚。 | 「她在害怕？她在保護我？」 |
| Stage 4 | 公會誌出現新字跡的那晚，她**沒回公會**。第二天回來。背上有傷。只說一句：「**他們也想要平靜。我懂他們。**」 | 「她回來了。她也是個人。」 |
| Stage 5 | 站起來：「**這次該我了。**」派或不派由玩家決定。 | 「該我選擇了。」 |

> **關於 Stage 1 / 2 的「舊紙條」細節**（v3.1 新增）：玩家不會被告知她口袋裡那張紙條是什麼。**它存在過就夠了**——Stage 4「我懂他們」就有了著力點。玩家會回想：**她口袋裡那張紙條是什麼？** 這個細節**永不揭曉**。

### 2.5 為什麼這個設計有力

| 傳統角色設計 | 奧菲莉雅 |
|---|---|
| 命運綁定主角 | 她沒有命運 |
| 神秘身份揭露 | 她沒有秘密（但她有過去——這不一樣） |
| 對主角忠誠 | 她不是為玩家活的 |
| 被劇本保護 | 她和大家一樣會死 |

她的力量是「**她和大家一樣**」——這正是這個遊戲核心幻想（你不是英雄，你是讓英雄誕生或殞落的人）的具體化身。

## 3. 異神（朦朧化重寫）

### 3.1 設計原則：異神不顯現，只有契者

**異神全程不命名、不顯形、不解釋**。所有可見現象的「原因」**只能歸結到契者的行為**。

異神是否真的存在？是抽象的存在？是契者的集體幻覺？是某個更古老的東西？**全劇本不解答**。

### 3.2 契者（the Bound）的具體設計

| 面向 | 設計 |
|---|---|
| **稱呼** | 自稱「契者」；外人多稱「**那群人**」、「異神信徒」、「**外來者**」 |
| **外觀** | 並非畸形——只是「**有些不對**」：眼神少了焦距、皮膚下偶有規律性的暗紋（玩家無法確認那是紋身、疤痕、還是別的東西）、姿勢角度過於放鬆 |
| **行為** | 不暴力、不威脅；他們**邀請**而不是強迫 |
| **能力** | **不擁有神祕力量**——他們做的事情都是「人類能做的」：勸說、聚會、留紙條、偶爾贈與物品 |
| **效果** | 他們所到之處，居民會**慢慢變得不一樣**——但這個變化**也可以用「集體心理現象」「特殊傳道技藝」「某種說不出來的鬆弛」來解釋** |

> **核心朦朧點**：契者**沒有任何超自然能力**。他們所做的事，**理論上人類都能做**。但他們做出來的效果，**讓人不敢確定背後是不是有更大的東西**。

### 3.3 載體 A 重寫：契者所在的村莊

舊版：「莊稼長得好、健康、孩童不哭」（過度具象化異神力量）
**新版**：村裡有契者居住。村民和契者一起生活。冒險者帶回的見聞——

> 「我去的那個村子，有幾個契者住在那裡。
> 村民跟他們相處得很好。
> 我問了一個老人，**她家以前的歌怎麼唱**。
> 她想了很久，說：『我們家以前會唱歌嗎？』」

關鍵調整：
- **不講「孩童」**（擴展版紅線）
- **不講莊稼/健康**（這些是異神力量直接顯現）
- **只描寫「失去」**——一個老人遺忘了自家的歌
- 失去的是**人之常情中柔軟的部分**——記憶、歌、某種莫名的傷感

**這個失去，可以歸咎於契者的某種長期影響，但也可以是時間本身。** 玩家無法確定。

### 3.4 載體 C 保留：契者的紙條

紙條**明確是具體的契者寫的**（不是異神的訊息）。內容偶爾**真的有用**——警告任務危險、提醒冒險者健康問題。

讓玩家面對：「**敵方給的建議是有用的**」這個倫理難題。

### 3.4.1 公會門口的紙條（v3.1 新增——朦朧但不缺席）

異神朦朧化的副作用：玩家可能變成「不在乎」。為了讓異神/契者**不被無視**，需要一個**直接抵達玩家公會的瞬間**——

**Stage 3 的劇情委託「北方廢墟尋找消失的學者」結算後**，公會門口出現一張紙條：

> 「你的人去過那地方。
> 我們知道。
> 沒有惡意。
>
> **願你睡得好。**」

這張紙條：
- 沒有威脅
- 沒有邀請
- **只是讓玩家知道「他們在看」**
- **「願你睡得好」這個善意的祝福**才是真正可怕的

玩家不知道這是契者寫的還是別人寫的——但這個訊息**直接抵達了玩家的公會**，這個「**直接性**」確保異神/契者**不會被玩家無視**。

> **設計平衡點**：朦朧但不缺席。這是異神設計的關鍵。

### 3.5 載體 B 取消：契者邀請場景

之前的「契者在路邊跟少女說話」——這個太戲劇、太直接。**取消**。

改為：玩家**只透過冒險者的口述**得知契者偶爾會邀請人。從未直接看見。**契者邀請的細節永遠是傳聞**。

### 3.6 異神的本質：永遠不解

劇終玩家**仍不知道**：
- 異神是否存在
- 它是什麼
- 它要什麼
- 它是惡是善

這是**設計上的選擇**——讓劇本承認自己無法處理的問題，而不是強行給答案。

## 4. 女神（隱晦陰影設計）

### 4.1 設計原則：女神是傳統意義的正義，但「正義」有隱晦的代價

不軟化女神的善（保留你最初的指示），但**讓「善」的執行細節有可解讀的陰影空間**。這個陰影：
- 對保守玩家：純宗教設計、無不適
- 對擴展版玩家：有可被擴展的隱晦暗示

### 4.2 「光輝者」體系（女神陰影的具體載體）

晨曦聖殿擁有「**光輝者**」——被女神選定、能直接接受神諭的人。

| 面向 | 隱晦設計 |
|---|---|
| **選定標準** | 含糊不清。聖殿說是「靈魂的純淨」，但實際上**也評估身體的完美** |
| **儀式** | 「**奉獻**」儀式——光輝者剃髮、穿白衣、深夜由祭司長**親自為其點亮聖徽**；過程私下進行，普通信徒不可旁觀 |
| **語彙** | 神諭與聖殿文書反覆使用「我的孩子」、「來到我的懷中」、「**接納你**」等——字面是純宗教的，但語境留下解讀空間 |
| **祭司長** | 獨身、年輕、面容極美；某些光輝者對他/她的崇敬**超過對女神的崇敬** |
| **被選定者的後續** | 他們進入聖殿後**不再公開出現**；只能透過聖殿的轉述得知他們「**過得很好**」 |

### 4.3 載體 D：被聖殿放棄的城鎮（Stage 4 任務見聞）

> 「我去的那個鎮子，去年瘟疫死了一半人。
> 鎮民問我，為什麼聖殿沒來。
> 我不知道怎麼回答。」

聖殿不是**惡的**——它只是**有自己的優先順序**。被優先的人是「光輝者」與聖殿的支持者；其他人，聖殿不傷害，**只是不看**。

### 4.4 與奧菲莉雅的對比（情感觸發點）

奧菲莉雅**不被聖殿選中**。Stage 2 三封信中的女神信，**不是寫給她的**——但她看了，她點頭。**她認可女神的方向，但她不在女神的名單上**。

這個微妙點將在 Stage 5 玩家面對「派她或不派她」時轉化為情感重量：**她的死亡（如果玩家派她）不會被聖殿記得，不會被女神迎接**。她就是死了。

### 4.5 設計效果（兩端對稱）

兩端都有具體的、可感知的、有立場的陰影：
- 異神：**失去你之所以為人的東西**
- 女神：**你不在被救的名單上**

玩家無論偏哪邊，都會**感受到代價**。沒有「正確選擇」——但每個選擇都有**具體的失去**。

> **擴展版設計空間**（v3.1 措辭調整）：本節 §4.2 的「光輝者奉獻儀式」是**雙重解讀空間**——保守版可解讀為純粹宗教儀式；擴展版可在文本層擴充其曖昧性。**大綱階段不在文本中明示**，留給後續劇本展開時依目標版本調整。

## 5. 五階段大綱（情感為主軸）

### Stage 1 — 一張紙條（World: E 和平）

- **threshold 提議**：8
- **觸發**：玩家經營公會約 1-2 天，接過幾個常規任務後，紙條從委託板「自己冒出」
- **紙條外觀**：泛黃、無署名、釘著一個鐵釘
- **委託內容**：「**護送一名沉默的旅人前往南方海岸**」（D 護送，C-01 categoryID=3）

**對話視窗（記憶點：金句）**：
> 委託板上多了一張紙條。
> 沒有署名。
> 上面只有一行字：
>
> **「他不會說話，但你會懂。」**

**奧菲莉雅的反應**（v3.1 強化）：
> 她看著那張紙條，**看了比平常久一點**。
> 「我去吧。」
> 她沒解釋為什麼皺眉。

**完成後**：
- 成功：冒險者帶回**一塊有奇異紋路的石頭**（公會場景擺飾物，FB-A1 啟動）
- 失敗：冒險者沒回來，但**石頭仍出現在公會門口**

**啟動的伏筆**：FB-A1（石頭顏色變化開始）、FB-S4（「他不會說話」短語埋下）、**FB-S9 奧菲莉雅看紙條的猶豫**（v3.1 新增）

**情感層級**：玩家**第一次發現「她有反應」**——這是日後產生情感連結的基礎。

### Stage 2 — 三封信（World: D 動盪）

- **threshold 提議**：22
- **觸發**：玩家從常規任務累積到 D 階轉換點

**對話視窗（記憶點：三封信並列；玩家不選擇）**（v3.1 第一封信微調，加入「使命」一詞）：
> 今早，公會收到了三封信。
>
> 第一封——「願女神的光，照在你的判斷上。**你被賦予了使命。**」
> 第二封——一張紙，上面是看不懂的符號，紙緣有焦痕。
> 第三封——「我是個學者。如果你看見了奇怪的東西，可以告訴我。」
>
> 三封信都沒有要求你做什麼。
> 你把它們收進了抽屜。

> **「使命」的設計用意**（v3.1）：「使命」一詞被刻意加重——玩家當下會感受到「我被賦予了什麼」。但隨著劇情推進，**這個詞從未被解釋**，最後玩家自己理解到——**所謂使命，可能只是有人這樣告訴你**。這個處理讓「使命」這個母題**被解構而非被刪除**。

**奧菲莉雅的反應**（v3.1 強化）：
> 她看了三封信。
> 對其中一封微微點頭。
> 然後她從口袋裡拿出**一張自己的舊紙條**，看了一眼，**收回去了**。

**之後的任務**：常規任務不變。輔軌（每日郵報變體、結算 flavor 微差）開始啟動。

**啟動的伏筆**：FB-S1（「鏡中無月」首次出現於某封信背景描述）、FB-A6（公會場景天空從藍色開始陰天）、FB-S6（奧菲莉雅對哪封信點頭——永不揭曉）、**FB-S10 奧菲莉雅口袋裡的舊紙條**（v3.1 新增——永不揭曉）

**情感層級**：玩家**第二次注意到「她在判斷」**——但她判斷的內容對玩家是封閉的。**這個封閉本身建立了她的內心深度**。

> Stage 1-2 對應「2~3 段全陣營通用」需求。**主軌完全通用**（三版玩家看到的對話文本一致）；**輔軌已開始微差**（郵報措辭、結算 flavor 依當前 styleTag 偏好）。

### Stage 3 — 鏡中無月（World: C 暗湧）

- **threshold 提議**：50
- **觸發**：玩家累積分數，世界進入暗湧階。**主軌訊息分軌正式啟動**

**對話視窗核心（記憶點：金句）**：
> 委託板上多了一張紙條。
> 上面只有一句話：
>
> **「鏡中無月。第七位請小心。」**

**主軌分軌呈現**（依玩家當前 styleTag 偏好；參考 §6 主軌分軌設計）：
- light 偏好：紙條工整、有微弱光暈、落款處有小小的晨曦聖徽
- dark 偏好：紙條字跡顫抖、紙緣焦痕、落款處是扭曲符號
- mixed/中立：普通紙條、無附加細節

**核心句子三版皆同**——玩家「**感覺到**」自己屬於哪一邊，但遊戲不明說。

**奧菲莉雅的反應**：**第一次拒絕**——「不該是我去。」推薦另一個冒險者去。

**之後的任務**：「**前往北方廢墟尋找消失的學者**」（B 調查，categoryID=3）

**任務結算文本（強分軌）**：
- light 偏好：冒險者帶回**學者的最後手稿，記錄了「女神之痕」的觀察**
- dark 偏好：冒險者帶回**學者的衣物，但人不見了——衣物上有契者的符號**
- mixed/中立：冒險者帶回**一張寫了一半的便條，內容看不懂**

**結算後特殊事件**（v3.1 新增）——公會門口出現紙條：

> 「你的人去過那地方。
> 我們知道。
> 沒有惡意。
>
> **願你睡得好。**」

**特殊事件**：如果奧菲莉雅推薦的那個冒險者死了——奧菲莉雅在公會角落坐了一整晚。她不哭，她不說話。**她就是坐著**。

**啟動的伏筆**：FB-S1（第二次出現，玩家可能開始注意到重複）、FB-S2（「第七位」首次出現）、FB-M1（light 任務的 jitter 開始偏負，玩家「最近運氣特別差」）、FB-A4（神諭排版開始有印錯）、**FB-S11 公會門口的契者紙條**（v3.1 新增）

**情感層級**：玩家對奧菲莉雅產生**三重疑問**——「她在害怕嗎？她在保護我嗎？她知道什麼？」她沒有回答。同時——**異神/契者第一次直接抵達玩家的公會**，朦朧但不缺席。

### Stage 4 — 沒回來的那一晚（World: B 危局）

- **threshold 提議**：120
- **觸發**：玩家累積分數，世界進入危局

**對話視窗（記憶點：場景變化，不靠文字）**：
玩家進入公會場景，**奧菲莉雅的椅子是空的**。桌上她平常喝的茶**第一次冷掉了**。

只有一行字：
> 她沒回來。

**第二天**：她回來。背上有傷。她不說發生了什麼。

她只說一句（**記憶點：金句**）：
> **「他們也想要平靜。我懂他們。」**

> 玩家此時可能想起 Stage 1 / 2 她口袋裡那張不解釋的舊紙條——**這是她「我懂他們」的著力點**。劇本不解釋，玩家自己連結。

**之後的任務（短，分軌）**：「**前往女神古殿，做出你的選擇**」（A 級任務，高死亡率）

**任務結算文本（強分軌）**：
- light 偏好：祭司在古殿迎接，但他承認「**女神有一段時間沒回應了**」
- dark 偏好：到達古殿時，**祭司不在了**，地上只剩聖徽碎片
- mixed/中立：古殿空無一人，留有一封信，「**自己決定吧**」

**啟動的伏筆**：
- FB-A2（公會誌出現新字跡，玩家可自行翻閱發現）
- FB-S2（「第七位」對照公會誌得知是某位前任公會長）
- FB-S3（之前的見習祭司「凡」重新提及，但**不是輪迴設定**——他只是個失蹤的祭司，可能加入了契者）
- FB-M1（揭曉：女神不在了，已有一段時間）
- FB-M2（如果玩家累積死亡 5 名以上冒險者，公會誌新字跡多一句「**我數過了，你失去了五個**」）
- FB-A7（奧菲莉雅椅子的茶杯第一次冷掉）

**情感層級**：玩家對奧菲莉雅產生**共感**——她去了某個地方、回來了、沒成為英雄、沒成為叛徒、**只是回家了**。這是劇本最有力的情感重量點。

### Stage 5 — 最後的椅子（World: A 末世）

- **threshold 提議**：200
- **觸發**：玩家累積分數至 A 階陣營閘
- **本階段機制本質（v3.1 明確）**：採 **A 案——劇情委託設計上必死**（無論誰去）。玩家的選擇本質是「**誰背負最後的死亡**」，不是「能否保住所有人」。

**對話視窗（記憶點：金句回到原點）**：
> 公會的天已經黑了。
> 委託板上只剩最後一張紙條。
> 上面寫著：
>
> **「他不會說話，但你會懂。」**

（FB-S4 揭曉：與 Stage 1 第一張紙條同句。）

**奧菲莉雅站起來**：
> **「這次該我了。」**

**玩家的選擇（dialogueKey 二元分支，A 案——必死前提）**：

| 玩家行動 | 後續 |
|---|---|
| **派奧菲莉雅** | 任務文本動態引用她的名字（FB-M3）。**她不會回來**。她的椅子從此空著。 |
| **不派奧菲莉雅，派別人** | **那個別人也會死**。**奧菲莉雅在椅子上看著玩家做這個選擇**。她不勸阻、不催促、不說話。她的「該我了」這個時刻被玩家拒絕——但她從不抱怨。 |

> **A 案的設計重量**：「保住所有人」不是選項。劇本拒絕給玩家「樂觀結局」的可能性——這是末世的本質，也是「玩家承擔」這個情感能成立的前提。

**任務完成後（無論結果）**：
公會誌的最後一頁，**自動寫完了未完的句子**——但寫的人**不是「下一任公會長」**（取消輪迴設定），而是奧菲莉雅本人。
- 如果她活著，她寫了
- 如果她死了，**字跡仍出現了**——她在最後的那段時間裡偷偷寫的

**最終揭示（隱晦處理，v3.1 修正）**：玩家終於明白「公會誌」是什麼東西——它**不是命運書、不是傳承物**，**就是奧菲莉雅自己想寫的東西**。她從前任公會長遺留的書信、碎紙、村人傳聞中拼湊出歷代公會長的故事，她**沒有被任命、沒有被指示、沒有任何傳承**——她只是個喜歡記錄的人。

劇本不揭露異神是什麼、不解釋女神為何離開、不給予公會長身份的「真正答案」。**但玩家會懂**。

> **這個設定徹底謙卑**：公會誌不是任何神聖之物，**就是一個沉默的傭兵在打發時間時寫的東西**。比任何神秘感都更動人。

**啟動的伏筆**：FB-S4 / FB-A1（石頭碎裂）/ FB-M3 全部揭曉；FB-S8 改為「公會誌字跡 = 奧菲莉雅自己想記錄」（見 §7.2）

**情感層級**：玩家**承擔**——不是被選中、不是命中註定，是**自己選擇了讓誰死**。

**遊戲不會 Game Over**。玩家可以繼續經營公會、繼續派遣冒險者，每個冒險者死亡都成為「下一任公會長將會讀到的記錄」——但這次不再有奧菲莉雅。

> **譚恩的接班**（與 §13 連結）：玩家最後一次離開公會時，會看見譚恩坐在那張椅子上，提筆寫字。**他是劇本「之後」的承諾**——這個世界不會因為奧菲莉雅或玩家的離去而失去記錄。

## 6. 訊息環境三軌設計

### 6.1 三軌結構

| 軌道 | 載體 | 分軌策略 |
|---|---|---|
| **主軌** | FT-09 階段對話視窗 | Stage 1-2 通用；Stage 3 形象與口吻分軌；Stage 4-5 詮釋分軌——核心事件相同，文本變體 |
| **輔軌** | 每日郵報（待 P-03 設計） | 全程根據 styleTag 累積偏好變體 |
| **微軌** | 任務結算 flavor text | 每次結算時根據 styleTag 偏好微調語氣 |

### 6.2 主軌分軌設計（Stage 3 為例，已於 §5 Stage 3 展示）

事件本體：玩家收到一張無署名紙條，內容「鏡中無月，第七位請小心」。
**根據隱藏陣營分數呈現的版本**：
- light 偏 high：工整祭司筆跡、紙質乾淨、有微弱光暈、落款晨曦聖徽
- dark 偏 high：顫抖字跡、紙緣焦痕、不規則暗紋、落款扭曲符號
- mixed/中立：普通紙條、平凡字跡、無附加細節

**核心句子三版皆同**，但**收到時的「氛圍」完全不同**。

### 6.3 輔軌分軌設計（每日郵報）

> 依使用者前次要求**先不寫**；本節僅展示分軌邏輯範例，待後續單獨設計時建立 `[FT-09-LORE] daily-gazette.md` 子文件。

範例：同一新聞主題「北方城鎮的祭司公開譴責異神信徒」
- light 偏 high：「**北境祭司公告：信仰仍在**」（強調聖殿團結、援助有成果）
- dark 偏 high：「北境祭司在午夜公開演說，無人到場」（強調聖殿失勢、城鎮已變）
- mixed/中立：「北境城鎮事件：祭司公開演說」（平鋪直敘、無評價）

### 6.4 微軌分軌設計（結算 flavor text）

冒險者「亞倫」（範例名）在 D 級護送任務中死亡：
- light 偏 high：「亞倫的歸途，將有人引領。」
- dark 偏 high：「亞倫在路上不見了。」
- mixed/中立：「亞倫未能歸來。」

> 玩家在數百次結算中累積感受，**這個累積比劇情階段對話更有滲透力**——是「3 分鐘 session」節奏下的記憶設計核心（見 §8）。

### 6.5 Jam 版分軌實作策略

| 軌道 | Jam 版實作優先序 | 備註 |
|---|---|---|
| **主軌的 Stage 5 二元分支**（奧菲莉雅死/活） | **必做** | dialogueKey 機制最低門檻，僅需 2 個變體 key |
| 主軌的 Stage 3-4 styleTag 三軌變體 | 待 P-03 啟動後再實作 | 文本量大；可降級為「全玩家看同一版本」 |
| 輔軌（每日郵報） | Post-Jam | P-03 通知系統設計暫緩 |
| 微軌（結算 flavor） | 可選 | 文本量大但結構簡單；若 Jam 後期時間允許可實作 |

### 7.4 伏筆設計原則

- **美術與機制伏筆不在文本中解釋**：玩家自己注意到才有意義；沒注意到也不影響核心循環
- **劇情伏筆透過文本對照才會顯露**：但**不彈窗、不 NPC 講解**
- **多個伏筆永不揭曉**（FB-S1 / FB-S6 / FB-S8 / FB-S9 / FB-S10）：劇本承認自己有「不明示的部分」

## 8. 減法設計與記憶點（3 分鐘 session 節奏的回應）

### 8.1 設計挑戰

玩家每天打開 30 分鐘、每次 session 3-5 分鐘、一個 stage 可能跨越好幾天——**碎片化下的劇情記憶**是真正的設計難題。

### 8.2 減法設計（每個 Stage 只記得一個東西）

| Stage | **唯一強記憶點** |
|---|---|
| Stage 1 | **「他不會說話，但你會懂。」**（金句） |
| Stage 2 | 三封信並列；奧菲莉雅對其中一封點頭 + 拿出口袋紙條（場景） |
| Stage 3 | **「鏡中無月。第七位請小心。」**（金句） |
| Stage 4 | 奧菲莉雅那一晚沒回來、茶冷了；她回來說「**我懂他們**」（場景 + 金句） |
| Stage 5 | **「這次該我了。」**（金句） |

> 全劇本核心金句**不超過 5 句**。其他文本都是包裝，不是記憶點。

### 8.3 記憶點增強設計

| 設計手法 | 具體實作 |
|---|---|
| **持續視覺存在** | 奧菲莉雅永遠坐在某張椅子上——玩家每天打開遊戲都看到。她的存在本身是記憶外掛 |
| **公會誌作為記憶外掛** | 玩家不需要記住所有伏筆——公會誌會自動記錄；玩家可隨時點開回顧 |
| **重複出現的元素** | FB-S1「鏡中無月」、FB-S4「他不會說話」——同一短語在不同 stage 重複，建立節奏感 |
| **無事發生的日常 vs 有事發生的瞬間** | Stage 之間的「日常時光」（接常規任務、看名冊、結算）越平淡，劇情瞬間越突出 |
| **金句設計** | 5 個 Stage 各 1-2 句金句，極短、可重複出現、可在郵報標題或結算文本中變奏 |

### 8.4 「3 分鐘 session」的具體呈現規範

| 規範 | 內容 |
|---|---|
| **每個 Stage 主對話視窗文字量** | **上限 3 行**（含金句） |
| **進入劇情視窗的觸發** | 必須能在 1 秒內讓玩家明白「這不是日常結算」（視覺差異 + 暫停感） |
| **劇情視窗可關閉** | 玩家可暫不處理；公會誌與委託板會保留標記 |
| **回顧設計** | 公會誌可隨時點開重看；劇情委託描述會保留至完成（不會像每日郵報般過期） |

### 8.5 Stage 推進節奏圖（v3.1 新增）

每個 Stage 不是「單一對話視窗 = Stage 完成」，而是**多視窗 + 玩家動作組成的推進序列**。每個視窗仍嚴守 3 行上限。

**Stage 1 / 2 / 3 的標準節奏**：
```
[解鎖視窗 ≤3行] → [玩家可立即關閉] → [委託板出現劇情委託]
                                    → [玩家自行決定何時派遣]
                                    → [派遣 → 等待結算]
                                    → [結算視窗 ≤3行]
                                    → [Stage 完成，回到日常]
```

**Stage 4 的特殊節奏**：
```
[解鎖視窗 ≤3行: 「她沒回來」] → [玩家進入公會場景，看到空椅子]
                            → [次日: 場景視窗 ≤3行: 「他們也想要平靜。我懂他們。」]
                            → [公會誌物件出現新字跡（玩家可主動翻閱，不強制）]
                            → [委託板出現劇情委託]
                            → [派遣 → 等待結算]
                            → [結算視窗 ≤3行]
                            → [Stage 完成]
```

**Stage 5 的特殊節奏**：
```
[解鎖視窗 ≤3行: 最後一張紙條]
   → [奧菲莉雅站起來，視窗 ≤3行: 「這次該我了。」]
   → [選擇 UI: 派她 / 派別人]
   → [派遣 → 等待結算（必死）]
   → [結算視窗 ≤3行: 動態引用名字（FB-M3）]
   → [公會誌最後一頁自動顯示，視窗 ≤3行]
   → [回到公會場景，譚恩坐在那張椅子上提筆寫字]
   → [Stage 完成 / 終局]
```

> **設計原則**：每個視窗短、可獨立消化、可被 3 分鐘 session 容納。Stage 4 / 5 的「重」不來自單一視窗的長度，而來自**多視窗在不同 session 間的累積**。

## 13. 職員系統的劇情整合（v3.1 新增）

### 13.1 三層分工架構

本劇本採用三層角色分工，互不重疊：

| 層次 | 角色 | 敘事功能 |
|---|---|---|
| **命運層** | 奧菲莉雅、其他冒險者 | 死亡、選擇、悲劇——劇情的核心情感重量 |
| **世俗層** | 職員（米拉、譚恩、凱拉、其他 gacha 職員） | 陪伴、日常、世界對玩家的回應 |
| **擴展層**（Post-Jam） | 職員的擴展互動（親密度、私人時刻、職員休息室擴充功能） | 情感投入、慾望、可能的失去 |

### 13.2 設計核心：動機 > 傷口

| 設計優先序 | 內容 |
|---|---|
| **第一順位：明確的動機** | 每個職員有「他們想做的事 / 想找的人 / 想成為的樣子」 |
| **第二順位：人格特徵** | 個性、說話方式、對世界的態度 |
| **第三順位：傷口（選用）** | 只有**少數職員**配傷口，且傷口要與動機**互相強化**而非「動機=療傷」 |

> 三個職員中**只有凱拉配傷口**。米拉、譚恩用動機 + 人格驅動。

### 13.3 職員的劇情功能（不推動主劇情）

職員不參與 5 個 Stage 的核心情節推進，但承擔以下劇情功能：

| 功能 | 設計 |
|---|---|
| **鏡子** | 職員的反應反映玩家的選擇 |
| **過渡** | 公會內部的日常戲——職員之間的互動讓公會「活著」 |
| **解構** | 職員是世俗的人，他們不在乎使命、神諭、陣營，他們在乎薪水、休假、誰跟誰好——**這個世俗性本身就是對前期「使命」敘事的解構** |
| **陪伴** | 玩家失去冒險者時，職員仍在；他們的存在是「之後」的承諾 |
| **擴展層的承載**（Post-Jam） | 親密度系統與私人時刻的承載 |

### 13.4 三個職員設定

#### 13.4.1 米拉（Mira）—— 女神陣營轉變

| 面向 | 設定 |
|---|---|
| **職位** | 見習聯絡官（FT-12 StaffTable，職能對映「**推薦接受率加成**」之類） |
| **factionID** | 1（女神） |
| **人格** | 明亮、認真到緊繃、努力過頭 |
| **動機** | **證明自己被女神選中** |
| **傷口** | 隱性——她其實是被聖殿**冷處理**的（覺得她不夠純粹但找不到正當理由退選她）。她不知道，或拒絕承認 |
| **視覺定位** | 公會角落的桌子（與奧菲莉雅椅子在不同方向）；桌上**一直擺著一封寄不出去的信**（給聖殿的彙報書，寫了又寫）；制服永遠燙得整齊，胸前別著聖徽 |
| **金句** | **「我寫了三遍。下次我會寫得更好。」** |

**陣營弧線**（v3.1 確定：分支實作放在米拉）：

| 弧線版本 | 米拉的轉變 | Jam 版實作 |
|---|---|---|
| **light 版本**（玩家偏 light） | 她的彙報書**真的得到了聖殿回應**。Stage 4 她可能收到聖殿的正式邀請——但她**選擇留下**，因為她覺得這裡才是「**女神真正想要她在的地方**」。她從「想被認可」轉變為「**自己定義價值**」 | **必做**——這是 Jam 版唯一陣營分支實作位置 |
| **通用版本**（mixed / dark / 中立） | 她的彙報書**從未得到回應**。她不哭、不鬧，只是寫得越來越短。Stage 4 她可能默默把胸前的聖徽收進抽屜——但她**還在工作**。她從「想被認可」轉變為「**沒被認可也照樣活下去**」 | **必做**——預設版本 |

**與主劇情的隱性連結**：
- 米拉與 Stage 4 揭露的失蹤祭司「**凡**」是**同期見習生**（待 §11.5 開放決策確認）
- Stage 2 三封信的第一封（女神信）—— 米拉看了會說一句：「**這個字跡我認得。是西側祭司的。他人很好。**」
- Stage 4「女神沒回應已有一段時間」的真相——她比玩家更早感受到，但她沒說

**抽到米拉的玩家會收穫**：
- 一個**透過聖殿視角看世界**的窗口
- 一個**「不被選中也努力活著」**的範本
- Stage 4 真相揭露時的**第二層情感重量**

| **傷口** | 無——他就是個有奇怪志向的年輕人 |
| **視覺定位** | 他總是站著（不像其他職員有自己的工位）；口袋裡**總有一支筆與一張紙**；偷偷觀察公會發生的事，包括奧菲莉雅在寫什麼 |
| **金句** | **「有些事，總要有人記下來。否則就像沒發生過。」** |

**通用弧線**（不分陣營，所有玩家看到同一版本）：

- **Onboarding ~ Stage 2**：他只是個普通雜役，玩家可能完全沒注意到他
- **Stage 3**：他開始**偷讀公會誌**——某個結算夜晚玩家可能看到他翻閱日誌的背影
- **Stage 4**：奧菲莉雅那晚沒回來時，**他通宵守在公會誌旁**——不是擔心日誌，是擔心「**沒人會繼續寫**」
- **Stage 5**：玩家會發現他開始**自己寫東西**——一本新的日誌，看起來像是模仿奧菲莉雅的字跡。他不是要取代她，他是**接著寫**。**玩家最後一次看到的公會場景是他坐在那張椅子上提筆寫字**

**與主劇情的隱性連結**：
- 他是公會誌的「**第二位讀者**」
- Stage 5 之後（無論奧菲莉雅死活），玩家最後一次看到的公會場景是——**譚恩坐在那張椅子上，提筆寫字**
- 他是劇本「**之後**」的承諾——這個世界不會因為奧菲莉雅或玩家的離去而失去記錄

**抽到譚恩的玩家會收穫**：
- 一個**沒有任何戲劇性背景**的角色——但他的存在感是**未來的承諾**
- 與奧菲莉雅形成「**這一代與下一代**」的並列敘事
- Stage 5 終局時的「**還有人在**」的情感支撐

> 譚恩是「**動機驅動，無傷口**」的典型範例——證明角色不需要黑暗過去也能有重量。

#### 13.4.3 凱拉（Kaira）—— 通用轉變（Jam 版無分支，dark 變體預埋 Post-Jam）

| 面向 | 設定 |
|---|---|
| **職位** | 委託官（FT-12 StaffTable，職能對映「**推薦時顯示成功率預估**」之類決策輔助效果） |
| **factionID** | 0（neutral；Post-Jam 啟用 dark 弧時可能調整） |
| **人格** | 沉穩、不多話、對所有人保持禮貌但不深交 |
| **動機** | **保護公會的人不被觸及** |
| **傷口** | **顯性——她曾經被契者觸及過**，但她逃出來了（3 個職員中唯一配傷口） |
| **視覺定位** | 她總是在委託板旁邊；**左手不戴手套**（普通人習慣戴），袖口可以看到一條**淡淡的暗紋**（玩家可能會注意到，可能不會）；喝茶但**不喝公會的茶**——她自己泡 |
| **金句** | **「我看過那些紙條。我不會碰它們。但我會看著你的人，不讓他們碰。」** |

**通用弧線（Jam 版默認）**：
- 她在公會逐漸找到歸屬
- **Stage 4 奧菲莉雅那晚沒回來時，她是第一個發現的**——她沒解釋為什麼她知道，只說「**我去找她**」然後出門。她帶她回來了（如果奧菲莉雅活著的話）
- 這是她從「**逃離過去**」轉變為「**擁抱現在**」的關鍵點

**dark 弧線（Post-Jam 預埋，Jam 版不實作）**：
- 她開始**重新理解契者**——她逃出來時是因為害怕，但隨著世界惡化，她開始懷疑自己當年的選擇
- 她不會回去，但她會說：「**也許他們不是錯的。只是太早了。**」

**與主劇情的隱性連結**：
- 她袖口的暗紋與 Stage 3 載體 A 村莊冒險者見聞中提到的「皮膚下的暗紋」**是同一種東西**——但凱拉的暗紋是**在褪色**。玩家自己對照才會發現
- Stage 4 奧菲莉雅那晚的關鍵情節由她承擔——她是「契者視角的倖存者」，這個視角無比珍貴
- 載體 C 契者紙條偶爾留下「有用的建議」——凱拉會看那些紙條，但**從不照做**。她保持距離但不否認對方

**抽到凱拉的玩家會收穫**：
- 一個**契者視角的倖存者**——這個視角無法從其他地方獲得
- Stage 4 主劇情的關鍵情感推手
- 「**離開了，但沒否定**」的成熟人物範本

> **設計小例外**（待 §11.5 第 12 項決策確認）：凱拉 Stage 4 主動去找奧菲莉雅——這稍微踩到「職員不參與主劇情」的線，但這個介入是必要的：她是契者倖存者，她是唯一能找到奧菲莉雅的人。

### 13.5 三個職員的對比與互補

| 維度 | 米拉 | 譚恩 | 凱拉 |
|---|---|---|---|
| **陣營** | 女神（light 轉變） | 通用 | 通用（Post-Jam 可選 dark） |
| **動機驅動** | 證明被選中 | 成為記錄者 | 保護不被觸及 |
| **傷口** | 隱性（被退選她不知道） | 無 | 顯性（被契者觸及過） |
| **視覺定位** | 角落桌、燙整齊制服、寄不出的信 | 站姿、筆與紙 | 委託板旁、不戴手套、自己泡茶 |
| **與奧菲莉雅關係** | 平行存在 | 接班者 | 守護者（Stage 4 找她） |
| **金句** | 「我寫了三遍。下次我會寫得更好。」 | 「有些事，總要有人記下來。」 | 「我看過那些紙條。我不會碰它們。」 |
| **抽到後玩家收穫** | 聖殿視角 + 不被選中也努力 | 沒有戲劇背景的範本 + 未來承諾 | 契者倖存者視角 + 離開但不否定 |

**互補性**：
- 米拉：被傳統權威系統考核的人 →「**證明**」
- 譚恩：自我驅動、不需要外部認可的人 →「**創造**」
- 凱拉：經歷過、活下來、做選擇的人 →「**守護**」

三種人格涵蓋三種**對待這個世界的態度**，沒有重疊。玩家無論抽到哪一個都能獲得一個獨特視角。

### 13.6 分支差異成本評估

依使用者前次決策，職員系統的陣營分支採「**1 陣營轉變 + 通用轉變**」成本控制：
- **米拉**：女神（light）+ 通用 兩個版本（Jam 版實作）
- **譚恩**：通用單一版本
- **凱拉**：通用單一版本（Jam 版）；dark 變體 Post-Jam 預埋

**情感連結評估**：

| 連結層次 | 來源 | Jam 版能否達成 |
|---|---|---|
| **層次 1：「我認識他、我喜歡他」** | 角色紮實人物鉤子、日常視覺存在、與玩家累積互動 | ✅ 不需要分支差異 |
| **層次 2：「他因為我而改變」** | 玩家選擇導致角色不同走向 | ✅ 透過米拉的兩個版本實現（其他職員停留在層次 1） |

**結論**：Jam 版資源下停在層次 1 已經夠了，米拉作為「**唯一具備層次 2 體驗的職員**」是恰當的成本配置。分支差異的真實價值是「**讓玩家想重玩的動力**」與「**情感連結的天花板提升**」——不是「初次建立情感連結的核心」。

### 13.7 抽 gacha 的驅動力設計

| 玩家心理 | 三個職員如何回應 |
|---|---|
| **能力獲取** | 既有 stat 加成（不變） |
| **角色魅力** | 三種強烈不同的人物鉤子，玩家會「想要那個特定的人」 |
| **故事投入** | 抽到 = 解鎖獨特視角（聖殿內幕 / 記錄者傳承 / 契者倖存） |
| **重玩動力** | 想看不同陣營下米拉的兩個版本、Post-Jam 看凱拉的兩個版本 |
| **完整性追求** | 三個職員集齊 = 看到世界的三個面 + 與奧菲莉雅形成完整的公會生態 |

抽 gacha 的真正動機**不是「我想要更強」，是「我想要那個人」**。給每個職員一個讓人想要的鉤子，gacha 慾望就建立了。

### 13.8 奧菲莉雅與擴展層的界線（v3.1 明確）

**這是設計上的硬性原則**：

| 角色 | 可參與擴展層（親密度 / 私人時刻） |
|---|---|
| **奧菲莉雅** | ❌ 完全不參與 |
| **其他冒險者** | ❌ 完全不參與 |
| **三位職員（米拉、譚恩、凱拉）** | ✅ Post-Jam 擴展層的承載者 |
| **其他 Post-Jam 職員** | ✅ 同上 |

**設計理由**：
- 奧菲莉雅的力量在於「她和大家一樣」「她會死」「她不被神話加持」
- 一旦她變成玩家的性對象，她就**不再是「同事」**——她變成了「我擁有的人」
- 這個「擁有感」會直接破壞 Stage 5「派她或不派她」的純粹重量
- 玩家送她去死的痛感，會被「她是我曾經親密的人」這件事**美化**——但這是**廉價的美化**

**敘事原則**：「**悲劇對象**」與「**慾望對象**」不能是同一個人——這不是道德問題，是**敘事重量分配**。保持奧菲莉雅的純度（即使聽起來保守）才能讓她的死亡有真正的重量。

### 13.9 Post-Jam 親密度系統預埋

依使用者前次決策，親密度系統 **Post-Jam 處理**，當前 GDD 不動。但設計接口需預埋：

| 設計接口 | 預埋方式 |
|---|---|
| **隱藏「親密度」參數** | 對應 FT-12 StaffInstance 結構新增隱藏欄位（Post-Jam 啟用） |
| **私人事件觸發機制** | 對應 FT-08 / FT-12 的事件系統擴充（Post-Jam 啟用） |
| **職員休息室擴展功能** | FT-07 BuildingTable 預留擴展槽（Post-Jam 啟用） |
| **職員「轉變」與「離開」的可能性** | 對應 FT-12 StaffInstance 狀態機擴充（Post-Jam 啟用） |

**Jam 版實作範圍**：三位職員的人物設定 + 主劇情隱性連結 + 米拉的陣營分支文本——其他擴展層內容**全數延後**。
