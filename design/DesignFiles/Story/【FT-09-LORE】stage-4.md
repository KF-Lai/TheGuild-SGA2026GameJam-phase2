## 4. 奧菲莉雅的反應（分為兩階段）

### 第一階段——缺席（Stage 4 解鎖時）

### 動作（極短）

# 文字：奧菲莉雅不在公會。
椅子空著。
茶杯冷了。

### 視覺呈現需求

# 美術：
- 公會場景中奧菲莉雅的椅子為空（無身體、無動畫）
- 椅子上的茶杯靜靜擺著，杯口冒著白色蒸氣消散（表示已冷）
- 光線昏暗（對應危局世界觀）
- 椅子周邊可能有她遺留的小物品（衣物邊緣、書頁角落）——暗示她確實存在過

### 對話（如果有）

# 文字：（無台詞——只有場景靜默）

---

### 第二階段——返回（次日）

### 動作（極短）

# 文字：她回來了。背上有傷。
她不說發生了什麼。
只說一句。

### 視覺呈現需求

# 美術：
- 奧菲莉雅重新坐在椅子上，背上可見繃帶或傷痕（視覺效果見 Character Art 需求）
- 她的姿勢比平常更加疲憊——靠向椅背，肩膀略微下沉
- 眼神空洞但不是悲傷——像是看透了什麼
- 新茶杯出現在她手邊（替換了冷茶）
- 光線略微轉亮（她的回歸帶來了某種確定性）

### 對話

# 文字：「他們也想要平靜。我懂他們。」
（共 1 句，配額內；這是全劇本最重的台詞之一）

## 5. 劇情委託內容（categoryID=3）

### 委託名稱

# 文字：前往女神古殿，做出你的選擇

### 委託描述

# 文字：女神古殿在山巔。派一位冒險者上去，看看古殿還存不存在，看看是否還有人在那裡。這是最高難度的任務。回來的人需要帶回「答案」——不知道是什麼答案。也許他們會死在那裡。也許他們會看見不該看見的。但這是現在必須問的問題。

### 委託難度與機制

- difficulty: A
- typeID: 4（調查）
- factionID: 1
- isScriptedDeath: 0
- requiredTraitID: 0

### 結算 Epilogue 文本

#### 成功（如果可成功）

- light 偏好：# 文字：冒險者到達古殿。祭司在那裡，但他承認「女神有一段時間沒回應了」。一切很安靜。
- dark 偏好：# 文字：冒險者到達古殿。祭司不在了，地上只剩聖徽碎片和燃燒的痕跡。
- mixed/neutral：# 文字：冒險者到達古殿。古殿空無一人，只留有一封信：「自己決定吧。」

#### 失敗 / 死亡

- light 偏好：# 文字：冒險者沒有回來。但古殿方面傳來了回信，裡面是關於那位冒險者最後見到的景象。
- dark 偏好：# 文字：冒險者失蹤於山路。聖殿沒有派人去找。古殿也沒有回應。
- mixed/neutral：# 文字：冒險者的遺物被送回——一只破損的聖徽護符，沾滿了灰燼。

## 6. 場景物件變化（複數）

### 公會誌動態字跡（FB-A2 / FB-A4 顯著）

# 美術 / 動畫：
- 公會誌在玩家訪問時，頁面自動翻至最新條目
- 新字跡出現（逐漸浮現動畫，1-2 秒）
- 女神神諭排版變化明顯（FB-A4）：之前工整的排版現在出現重排、字跡顫抖、偶有印錯或塗黑部分
- 玩家可翻閱全冊查看「第七位」的公會長記錄（FB-S2 揭曉點：某位前任就是「第七位」）

### 茶杯冷卻過渡（FB-A7）

# 美術 / 動畫：
- Stage 4 期間，每當奧菲莉雅出現時，她身邊的茶杯視覺會緩進冷卻（顏色變灰、蒸氣消散）
- Stage 5 開始前，茶杯完全冷卻、空著

# 美術 / 動畫：
- 天空顏色進一步深化為近紫色（危局階特色）
- 不會再亮回去（單向陰暗設計，對應 §4.2 性質宣告「光進入後不退回」）

## 8. 機制觸發 / 系統事件

# 機制：
- FT-09 階段解鎖機制觸發（factionScore >= 120）
- **specialEventKey = "ophelia_missing" 觸發**：P-02 收到 `OnFactionStoryStageUnlocked` 事件後，於對話確認時發布 `OnOpheliaMissingNight` 事件
  - C-02 SetWounded(opheliaInstanceID) 被調用，woundedUntilTimestamp 設為當前時間 + 12 小時
  - P-02 場景物件狀態更新：奧菲莉雅椅子從「present」轉為「empty」（視覺狀態變化）
  - 公會場景進入「夜間模式」（可選視覺效果）
- **OnOpheliaReturned 事件序列**（次日或 12 小時後）：
  - C-02 adventurer.woundedUntilTimestamp 到期，自動觸發 OnAdventurerRecovered
  - FT-09 訂閱此事件，識別 instanceID 為奧菲莉雅，發布 OnOpheliaReturned
  - FT-09 同步調用 TriggerDeferredStageCheck（用於 Stage 5 blocker 檢查）
  - P-02 場景物件狀態回滾：椅子從「empty」轉為「present」
  - C-02 再次 SetWounded(opheliaInstanceID)，woundedUntilTimestamp 設為當前時間 + 6 小時（標準 WOUNDED_RECOVERY_HOURS）
- C-01 categoryID=3 第四個委託呈現
- **FB-M2 訂閱 FT-04 死亡事件**：每當 `OnAdventurerDied` 發布，FT-09 內部計數 `_totalAdventurerDeaths++`；若 >= 5，公會誌補加一句
- **FB-A4 女神神諭排版變化**：任何女神相關的信息或神諭文本，排版開始出現視覺瑕疵（由美術資產層實現）
- 公會誌新增字跡（FB-A2 第四段 + 可選 FB-M2 補充）
- 奧菲莉雅回歸事件發布（供後續劇本與 UI 層使用）
- **背景天空進入「危局色」（近紫）**——不會再淡化，持續至遊戲結束
