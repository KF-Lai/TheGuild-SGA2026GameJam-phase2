## 1. 解鎖對話視窗（dialogueKey: story.aurorae.stage2）

### 通用版（common）

# 文字：今早，公會收到了三封信。
第一封——「願女神的光，照在你的判斷上。你被賦予了使命。」
第二封——一張紙，上面是看不懂的符號，紙緣有焦痕。
第三封——「我是個學者。如果你看見了奇怪的東西，可以告訴我。」

三封信都沒有要求你做什麼。
你把它們收進了抽屜。

## 2. 紙條視覺與文字內容（三封信並列）

### 紙條金句

# 文字：（無單一金句，而是「三封信並列」作為視覺記憶點）
第一封的開頭：「願女神的光……」
第二封的核心：看不懂的符號
第三封的語氣：「如果你看見了奇怪的東西……」

### 紙條視覺規格

# 美術：三封信各有不同呈現（stage 2 統一版）

**第一封——女神信**
- 紙質：米白，略帶聖殿風格的花紋水印
- 字色：深棕墨水，筆跡工整有力
- 紙緣：整齊，四角無損
- 落款：微小的晨曦聖徽（金色或淺金色）
- 語氣視覺：莊嚴、正式

**第二封——異神信**
- 紙質：灰黃色，質感粗糙
- 字色：極深幾乎純黑，符號不規則
- 紙緣：上緣撕裂，左右兩側不規則，右下焦痕明顯
- 落款：扭曲線條符號（不規則橢圓加十字）
- 語氣視覺：混亂、不詳

**第三封——學者信**
- 紙質：標準米白，泛黃較輕
- 字色：深灰色，筆跡工整但帶手寫感
- 紙緣：輕微折痕，對稱磨損
- 落款：無落款或單一破折號「—」
- 語氣視覺：科學、低調

### 紙條呈現動畫

# 動畫：三封信逐一顯現在委託板上（各間隔 0.5 秒），每封出現時有短暫落地動畫（紙張輕微抖動）

## 3. 奧菲莉雅的反應

### 動作（極短）

# 文字：她看了三封信。
對其中一封微微點頭。
然後她從口袋裡拿出一張自己的舊紙條，看了一眼，收回去了。

### 視覺呈現需求

# 美術：奧菲莉雅依次掃過三封信，眼神在某一封停留更久（點頭的那一封——永不在文本中揭曉）；她從椅子扶手邊的暗口袋緩緩拉出一張舊紙條（紙質泛黃、邊角破損），眼神飄向窗外 2 秒，然後將紙條重新放入口袋。動作極慢、極輕、帶著某種習慣性的儀式感。茶杯仍在手邊，未動。

## 4. 劇情委託內容（categoryID=3）

### 委託名稱

# 文字：世界動盪的信息

### 委託描述

# 文字：有人想知道最近發生的事。他們不說明身份，只要求一份「看見了什麼」的報告。可能是貿易商，也可能是其他人。報酬是三份不同的信息——選一份帶回來。風險等級突然上升。世界在改變。

### 委託難度與機制

- difficulty: C
- typeID: 4（調查）
- factionID: 1
- isScriptedDeath: 0
- requiredTraitID: 0

### 結算 Epilogue 文本

#### 成功（如果可成功）

- light 偏好：# 文字：冒險者帶回了一份報告。上面提到女神的蹤跡——聖殿仍在活動，信徒在增加。世界未改變。
- dark 偏好：# 文字：冒險者帶回了一份報告。內容顯示有新的勢力在暗處擴張。聖殿正在失勢。
- mixed/neutral：# 文字：冒險者帶回了一份報告。內容模棱兩可，聖殿、學者、其他勢力都有行動跡象。

#### 失敗 / 死亡

- light 偏好：# 文字：冒險者沒回來。一週後，那份報告自己出現在了公會門口。沒人簽名。
- dark 偏好：# 文字：冒險者失蹤。報告仍被送來了——但內容是空白的。
- mixed/neutral：# 文字：冒險者未歸。報告被留在了公會門口，收件人只寫著「公會長」。
