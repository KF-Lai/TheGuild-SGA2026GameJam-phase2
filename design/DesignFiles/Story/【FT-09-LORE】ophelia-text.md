## 2. Onboarding 開場場景

### 場景描述

# 美術：晨光灑進公會。藍色清爽的天空透過窗戶投進來。公會內部簡樸整齊——長木桌上有疊羊皮紙，牆上釘著委託欄。靠窗的角落有一張老舊但擦拭得很乾淨的椅子。茶杯在椅子邊的矮桌上冒著白煙。

### 奧菲莉雅進場與對話

# 文字：
你打開公會的門。
椅子上的人抬起頭。

「你來了。我等了一個月。」

她站起來，走到你身邊。她的身形不高，但姿態沉穩。

「桌上的事，由你決定。地上的事，我們一起。」

她回到椅子上，拿起茶杯。
你明白了。

### Stage 5 結算動畫描述

#### 分支 A：派遣奧菲莉雅（死亡路線）

# 美術 / 動畫：
- 奧菲莉雅從椅子上站起，走向委託板
- 她用手指尖輕輕觸碰紙條
- 她轉身，看向玩家的位置
- 她沒有說話，但微微點頭
- 她走向門外，身影漸漸模糊、消失於黑暗中
- 她的椅子逐漸靠向鏡頭，永遠空著

# 文字（結算視窗，依 styleTag）：

她沒有回來。
椅子從此空著。

**dark 版（dialogueKey: story.aurorae.stage5.epilogue.dark.dead）**

她走進了黑。
再也沒回來過。
椅子空了。

**mixed/neutral 版（dialogueKey: story.aurorae.stage5.epilogue.neutral.dead）**

任務完成。
代價是她的離去。
椅子永遠空著。

---

#### 分支 B：派遣他人（奧菲莉雅活著）

# 美術 / 動畫：
- 玩家選擇「派另一個冒險者」
- 奧菲莉雅坐回椅子上，沒有表情變化
- 她看著玩家做出這個選擇
- 她的眼神深邃但不責備
- 她不勸阻、不催促、不說話
- 所選冒險者走向委託板，走向門外，消失於黑暗中
- 奧菲莉雅仍坐在椅子上，茶杯在手邊（已冷）

# 文字（結算視窗，依 styleTag）：

**light 版（dialogueKey: story.aurorae.stage5.epilogue.light.alive）**

她沒有去。
冒險者去了，沒有回來。
椅子仍然有人坐著。

**dark 版（dialogueKey: story.aurorae.stage5.epilogue.dark.alive）**

你選擇了她以外的人。
那個人消失了。
她還在這裡。

**mixed/neutral 版（dialogueKey: story.aurorae.stage5.epilogue.neutral.alive）**

任務派遣完成。
死掉的是另一個人。
她活著，坐在椅子上。

## 8. 關鍵伏筆對應（不在文本中直接揭示，作為設計參考）

### FB-S9：Stage 1 看紙條的猶豫

# 機制：奧菲莉雅看到紙條「他不會說話，但你會懂」時，有短暫的停頓與皺眉。這個反應永不解釋——玩家到 Stage 4「我懂他們」時才能回頭思考這一刻的含義。

---

### FB-S10：Stage 2 口袋裡的舊紙條

# 機制：奧菲莉雅從口袋拉出一張泛黃的舊紙條，看了一眼，收回去。這張紙條的內容永不揭曉。玩家可以猜測、詮釋，但永遠不會知道上面寫了什麼。

---

### 沉默 trait 的 description 欄位文字

# 文字（≤30 字）：她不主動接受委託。需要公會長明確指派，她才會行動。這就是她的沉默。

## 10. 寫作風格指南（內部參考）

### 語氣特徵

- **簡潔、沉靜**：從不冗長敘述，重點落在空白與暗示
- **動詞驅動**：「她站起來」「她看著」「她坐著」——動作本身就是對話
- **視覺記憶點**：椅子、茶杯、紙條——具體物件承載情感
- **永不解釋**：伏筆終身不揭示，讓玩家自行詮釋

### 與其他角色的分別

| 角色 | 說話量 | 風格 |
|---|---|---|
| 奧菲莉雅 | 極少，每個 Stage 通常 ≤1 句 | 沉默、動作優先 |
| 米拉（聖殿聯絡官） | 正常 | 儀式感、信念感 |
| 譚恩（雜役） | 少 | 觀察者、局外人視角 |
| 凱拉（委託官） | 正常 | 務實、同情但保持距離 |

## 12. 場景物件相關文字需求

### 聖徽紋路石（FB-A1）

# 動畫描述（非玩家可見，僅美術參考）：
Stage 1 出現後，石頭開始 styleTag 連動的顏色週期變化：
- light 偏好：白色 → 淡金色 → 白色（循環）
- dark 偏好：灰色 → 紫紅色 → 灰色（循環）

### 公會場景背景天空（FB-A6）

# 動畫描述（非玩家可見，僅美術參考）：
- Stage 1 開始：清朗藍天
- Stage 2 期間：天空開始陰沉，籠罩淡灰色雲層
- Stage 3 期間：天空轉為黃昏色（不再淡化）
- Stage 4 期間：天空深化為近紫色（危局色）
- Stage 5 結算後：天空進入全黑或深紫（末世色）
