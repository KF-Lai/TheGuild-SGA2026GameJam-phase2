## 1. 專案脈絡

**遊戲**：The Guild — 放置型公會經營遊戲，玩家身為公會長，透過審核委託、招募冒險者、建設公會、招聘職員，間接影響冒險者命運。

**獨特性**：遊戲視窗是**桌面前置透明窗口**，常駐工作列上方，玩家工作或上課時可隨時瞄一眼公會狀態。視窗內是公會場景的橫幅景觀（從左至右：委託欄、大廳、建設區、保險箱、職員休息室、辦公桌），冒險者於底部地面層活動。

**核心情緒**：「偷看一眼」的滿足感、對 NPC 的情感連結、決策後的等待與驚喜/遺憾、有重量的破產終局。

## 2. 視覺定位

**主風格**：**日系動漫風 + 像素藝術混合**

- 場景層（A 類）：**Pixel Art**（中等密度，類 Stardew Valley / Tap Tap Loot），表現「桌面小窗口裡的迷你公會」
- 角色立繪（F-D）：**日系動漫半身像**（類 Granblue / 東方 Project / Atelier 系列），溫暖、有故事感
- UI 介面（D / E / F-A）：**手繪羊皮紙 + 木質 + 金屬包邊**（類 Darkest Dungeon 簡化版 / Slay the Spire），中世紀奇幻
- 對話氣泡（F-B）：**手繪線條風**，有質感但不過度裝飾

**整體色調**：
- 主色：暖色木質（深棕 #4A3520 / 淺棕 #B68A5C / 米白 #EFE4D2）
- 點綴：金屬金（#C9A961）、墨水深棕（#3B2A1A）
- 強調：成功綠（#6B9B6E）、危險紅（#A04848）、警告橘（#D4923A）
- 魔幻光：晨曦金（#F4D58A，奧蘿瑞陣營專用）、神秘紫（#5B4B7A，異神專用）

**禁用色**：
- **`#000000`（純黑）**：透明色鍵保留（P-01 桌面透明視窗用），任何元素禁用純黑；需要黑色時用近黑 `#0A0A0A` 以下色階

**禁忌風格**（negative prompt 必含）：
- `3d render, photorealistic, cluttered, glitchy, anime girl excessive moe, oversaturated, neon, cyberpunk, modern UI flat design`

## 3. 技術規格

### 3.1 解析度基準

- **基準解析度**：1920×1080（PC 主流）
- **視窗尺寸**：寬 = 螢幕可用寬（1920），高 = 可用高 × 0.30（約 312px）
- 所有資產以 1080p 為設計基準；高解析度（2K / 4K）由 Unity 縮放處理

### 3.2 檔案格式

| 項目 | 規格 |
|---|---|
| 格式 | **PNG-24 + Alpha（RGBA）** |
| 色彩空間 | sRGB |
| 透明背景 | 必須（除場景背景 A-01 外）|
| 色彩深度 | 8-bit / channel |
| 壓縮 | 無損 PNG |
| Pixel Art 設定 | 整數倍縮放友善（不使用反鋸齒插值的中間色）|

### 3.3 尺寸總覽

| UI 大類 | 建議尺寸範圍（px）| 說明 |
|---|---|---|
| **A 場景背景** | 1920×312 | A-01 全窗背景；可水平 tile |
| **A 場景物件** | 30×40 ~ 400×280 | 依物件大小（茶杯小 / 大廳建築大）|
| **B 場景內嵌** | 32×32 ~ 200×60 | 浮動 UI 元素 |
| **C 常駐 HUD** | 32×32 ~ 48×48 | 圖示尺寸 |
| **D 主面板** | 1200×280（大）/ 600×260（中）| 9-slice 可拉伸；窗內覆蓋 |
| **D 子元件（卡片）** | 280×120（卡）/ 180×80（小卡）| 委託卡 / 冒險者卡 |
| **E 模態彈窗** | 480×320（標準）/ 320×200（小型確認）| 居中顯示 |
| **F-A 按鈕** | 180×48（base，可 9-slice）| 含 4 態（default/hover/pressed/disabled）|
| **F-A 圖示按鈕** | 48×48 | icon-only 方型 |
| **F-A 滑桿** | 240×24（軌道）+ 24×24（thumb）| 9-slice |
| **F-B 對話框** | 720×180（標準）/ 240×60（hover 氣泡）| 9-slice 友善 |
| **F-B 紙條** | 240×600（直）| 直式 1:2.5 比例（v3.1 規格）|
| **F-B Toast** | 280×60 | 短訊條狀 |
| **F-C 圖示** | 32×32（小）/ 48×48（中）/ 64×64（大）| 統一方型 |
| **F-D 立繪** | 256×384 | 3:4 半身像 |

### 3.4 9-slice 與 atlas 友善

- 所有可拉伸 UI（按鈕、面板、對話框）需設計為 9-slice：四角為固定圓角/裝飾，邊緣可 tile
- 圖示集（F-C）建議產出時就考慮放入 sprite atlas，留 2px 邊距

### 4.2 Variant 命名

- 預設：`_default`
- 多變體：`_light` / `_dark` / `_neutral` / `_hover` / `_pressed` / `_disabled`
- 場景物件 sprite 變體：對齊 `SceneObjectStateTable.csv` 的 `spriteVariant` 欄位（如 `_idle` / `_empty` / `_present` / `_cold`）
- 編號變體：`_01` / `_02`（如多張紙條）

### 4.3 GPT 輸出檔名建議

GPT 為某項生成 prompt 時，請於 prompt 區塊上方標明：

```
【UI-ID】<ID>
【檔名】<UI-ID>_<variant>.png
【建議路徑】Assets/Art/UI/<Category>/<檔名>
【尺寸】<W>×<H> px
```

## 5. 分類產出指引

### 5.1 A 場景層（Pixel Art）

**風格細節**：

- 暖色黃昏調，類似日落時分的公會工作日常
- 像素密度：每個物件約 24~80px 高（角色約 32~48px 高）
- 不使用次像素（sub-pixel）反鋸齒
- 建築有溫暖窗光，地面有微妙陰影
- **禁用 #000000**：陰影最深用 `#1A1410` 或更深

**場景背景 A-01**：
- 公會室內橫幅構圖，從左至右：委託欄區（昏黃公告板）→ 大廳入口（敞開大門 + 暖色內光）→ 中央活動空間（地毯、桌椅）→ 保險箱區（金屬保險櫃 + 木桌）→ 職員休息室區（沙發、茶几）→ 辦公桌區（公會長辦公桌）
- 透明區域：天花板、地板下方完全透明（玩家桌面顯露）

**場景物件（A-02~A-12）**：
- 每物件獨立 sprite，可放置於背景前景
- 互動物件需有可辨識的「召喚感」（輕微發光、輪廓提示）
- 奧菲莉雅敘事物件（A-08~A-12）需符合 v3.1 patch 規格（見 §7）

### 5.2 B 場景內嵌（Pixel Art / 簡化 illustration 混合）

**風格細節**：

- 嵌在場景上方的浮動數值與圖示
- 與場景同色調但略加亮度，突顯出來
- 字體：等寬數字（金額、倒數）
- 不阻擋場景主體；採用半透明底襯（80% 不透明度）

### 5.3 C 常駐 HUD（Illustration 圖示）

**風格細節**：

- 暖金屬包邊圖示，類「中世紀羊皮卷封印」
- 尺寸 48×48，留 4px 邊距內縮
- Hover 時亮度提升 15%；Pressed 時下沉 1px

### 5.4 D 主面板（手繪羊皮紙 + 木質框）

**風格細節**：

- 框架：深棕木質邊框（4~8px 寬），帶輕微紋理；四角金屬鉚釘裝飾
- 背景：羊皮紙質感（米白偏黃，輕微紋理噪點 3~5%）
- 標題列：深棕橫條 + 金色標題文字
- 關閉按鈕（X）：右上角金屬圓鈕
- 內容區：分區明確，各區用細線分隔（深棕 1px）
- 9-slice 設計：四角 32×32 為固定區，中央可拉伸

**子卡片**（D-01a 委託卡 / D-02a 冒險者卡）：
- 280×120 標準卡 / 180×80 小卡
- 卡片邊框：金色細邊 + 圓角 8px
- 卡片底色：依狀態變化（Idle 米白 / Dispatched 淡藍 / Wounded 淡紅 / Dead 灰）

### 5.5 E 模態彈窗（D 風格延伸）

**風格細節**：

- 沿用 D 主面板風格，但更精緻、更小尺寸
- 標準彈窗 480×320：標題 + 訊息 + 兩個按鈕（確定 / 取消）
- 危險彈窗（E-02a / E-08）：邊框與按鈕轉為深紅色調，提醒不可逆操作
- 訃聞畫面（E-05）：整窗灰調，黑底白字標題「公會的終章」
- 結算畫面（E-06）：整窗暖金色，類「公會編年史」古書風格

### 5.6 F-A 通用控制元件

**風格細節**：

- 按鈕：木質底 + 金屬包邊，4 態必備
  - Default：深棕木紋 + 米白文字
  - Hover：亮度 +15%、輕微外發光
  - Pressed：下沉 1px、亮度 -10%
  - Disabled：灰調 50% 飽和
- 視窗按鈕（X / − / □）：金屬圓鈕，hover 時金色高亮
- 滑桿：軌道為深色凹槽，thumb 為金屬球
- Tab 切換：未選未底襯，選中時亮金色 + 下方 2px 金線

### 5.7 F-B 對話氣泡框（依用途分風格）

**標準角色對話框 F-B-01**：
- 720×180，左側 portrait 容器（160×160），右側文字區
- 圓角 12px，深棕邊框 + 米白底
- 底部三角指向 portrait（類漫畫對話框）

**旁白框 F-B-02**：
- 全寬橫條，無 portrait
- 深色半透明底（70% 不透明），白色襯字

**內心獨白 F-B-03**：
- 無外框、羽化邊緣
- 斜體字、米白色
- 微微飄浮感（淡淡光暈）

**場景說明層 F-B-06（Stage 4 「她沒回來」）**：
- 灰色字疊加在公會場景上，無框、半透明
- 字距寬鬆、行距 1.6×

**Stage 5 黑底白字最簡 F-B-07**：
- 全螢幕黑色（#0A0A0A，避開純黑）
- 中央白字、簡單襯線體
- 留白極多，極簡

**紙條三版 F-B-08~10**（v3.1 patch 規格）：
- 直式 1:2.5 比例（240×600）
- 字型大小 14pt，字數限 ≤2 行金句
- 進入動畫一致（飄落 + 微旋轉）

| 版本 | 紙質 | 字色 | 紙緣 | 落款 |
|---|---|---|---|---|
| **light** | 米白偏奶油，無明顯紋理，輕微羊皮感 | 深棕 `#3B2A1A` ~ `#2C1A0A`，工整 | 整齊，四角輕微缺損 1-2px | 極小晨曦聖徽 4×4px（Stage 3+）|
| **dark** | 灰黃色，紙漿雜質感 3~5% 顆粒噪點 | 近純黑 `#1A1A1A` ~ `#0D0D0D`，顫抖 ±1-2px、基線傾斜 1-2° | 不規則撕裂（上緣或左緣）+ 右下焦痕（Stage 3+）| 扭曲線條符號（不規則橢圓加十字）|
| **neutral** | 米白接近標準白，輕微泛黃 | 深灰 `#2E2E2E` ~ `#222222`，正常 | 輕微折痕，對稱磨損 | 無落款或單一 `—` 破折號 |

**Toast 短訊 F-B-11~13**：
- 280×60 條狀
- 圓角 8px，左側色帶（4px 寬）標識類型：綠 / 紅 / 黃
- 半透明深色底（90% 不透明）+ 白字

**Tooltip F-B-14**：
- 自動寬度（最大 240px），高度依內容
- 深棕底 + 米白字，圓角 4px
- 細邊框 + 微陰影

### 5.8 F-C 圖示集（統一風格）

**通用規格**：
- 32×32 / 48×48 / 64×64 三種尺寸
- 暖金屬包邊（2px）+ 深色內景
- 留 4px 內距，避免邊緣切到
- 統一線條粗細與光源方向（左上 45°）

**重點圖示組**：
- **F-C-02 職業 ×7**：戰士（劍盾）/ 法師（書本魔杖）/ 弓箭手（弓箭）/ 盜賊（匕首）/ 牧師（聖徽）/ 學者（卷軸羽毛筆）/ 工匠（鐵鎚扳手）
- **F-C-05 難度標籤 ×9**：F~SSS 漸層配色，F~D 灰銅、C~A 銀、S~SSS 金紅，字母大寫粗體
- **F-C-09 陣營徽記**：奧蘿瑞晨光聖徽（金色光暈太陽 + 八芒星）、其他陣營待補
- **F-C-10 危險度 ×5**：和平（綠葉）/ 動盪（橘火星）/ 暗湧（紫漩渦）/ 危局（紅警告三角）/ 末世（黑暗骷髏）

### 5.9 F-D 角色立繪

**通用規格**：
- 256×384（3:4 半身像）
- 透明背景
- 日系動漫風，半寫實，暖光打底
- 構圖：胸部以上至頭頂，頭部佔畫面 1/3，留適當頂部空間
- 表情符合角色個性（戰士英氣、法師深沉、學者書卷氣等）
- 服裝符合職業（不過度華麗）

**特殊立繪**：
- **奧菲莉雅 F-D-03**：銀髮少女騎士，灰藍長袍，胸前晨曦聖徽，憂鬱沉靜眼神
  - Stage 5 alive 變體：略顯疲憊但堅定
  - Stage 5 dead 變體：閉眼安詳、半透明光暈
- **米拉 501**：見習聯絡官，褐髮，活潑樣貌
- **譚恩 502**：雜役記錄者，黑髮，沉靜文書氣質
- **凱拉 503**：契者倖存者，淺紫髮，眼神帶創傷與堅毅

### 5.10 F-E 場景 Sprite 變體

對應 `SceneObjectStateTable.csv` 中 11 個 spriteVariant：
- `idle / empty / empty`（椅子）
- `present / cold`（茶杯）
- `unopened / annotated`（公會誌）
- `hidden / visible`（紋章）
- `posted`（門上紙條）

每個 sprite 之間需保持像素網格對齊與光源一致，玩家切換時無突兀感。

### 5.11 F-G 動畫元件

非單張圖；以 sprite sheet 或 sequence frames 產出：

- **F-G-01 金幣漂浮**：6 frames，向上飄浮 + 淡出
- **F-G-02 擲骰動畫**：12 frames，骰子翻滾後定格
- **F-G-03 卡片翻面**：8 frames，3D 翻轉
- **F-G-04 升級動畫**：10 frames，光柱上升 + 文字浮現
- **F-G-05 破產警告閃爍**：4 frames，紅色脈動
- **F-G-06 茶杯冷卻**：6 frames，蒸氣消散
- **F-G-07 字跡浮現**：依字數變動，逐字顯現
- **F-G-08 面板淡入淡出**：USS 動畫即可，不需 sprite

## 6. 變體與批次產出建議

### 6.1 一致性優先順序

當為一批 UI 產 prompt 時，**先固定共用視覺語彙再做變體**：

1. 先確立**色板樣本**（主色、點綴色、強調色）
2. 再確立**邊框 / 紋理樣本**（木質 / 羊皮紙 / 金屬）
3. 再產**字型樣本**（中文、英文、紙條手寫）
4. 最後逐項產 UI，反覆引用前三項

### 6.2 建議批次順序（對齊 UI-index §6 優先序）

| 批次 | 內容 | 理由 |
|---|---|---|
| **B0 視覺基準** | 色板 / 紋理 / 字型 / 1~2 個樣板按鈕 | 立 visual identity，後續所有 UI 引用 |
| **B1 通用控件** | F-A 全套（按鈕、視窗 chrome、滑桿等）| 所有面板的構成單位 |
| **B2 對話氣泡** | F-B 全套（含紙條三版）| FT-09 故事面板強依賴 |
| **B3 圖示集** | F-C 全套 | 跨面板廣泛使用 |
| **B4 主面板** | D-01 / D-02 / D-06 三大主畫面 | MVP 核心循環 |
| **B5 場景層** | A 全套 + B 內嵌 | 桌面窗口的視覺主體 |

medieval fantasy game ui button, dark wood texture base, golden metal trim, soft inner glow, parchment-style accents, hand-drawn outline, four-state button (default state), warm sunset palette, illustration style, transparent background, clean edges, 9-slice friendly

## 7. 奧菲莉雅 / 奧蘿瑞陣營專屬規格

劇本 v3.1 中的特殊視覺需求，需與其他 UI 區別。

### 7.1 奧菲莉雅角色視覺

- **基調**：銀色長髮、灰藍色眼神、晨曦色（金白）光暈點綴
- **服裝**：簡樸騎士袍，胸前晨曦聖徽（小巧不顯眼）
- **氣質**：沉靜、略帶憂鬱，有「她已經知道結局」的隱性感
- **Stage 5 二元變體**：alive 版略疲憊但堅定；dead 版閉眼安詳、半透明光暈、背景晨曦

### 7.2 晨曦聖徽（F-C-09 / A-11）

- 八芒星 + 中央太陽
- 主色金白（#F4D58A），輪廓金（#C9A961）
- 不對稱，左下角略缺損（暗示「不完整的神」）
- Stage 1~2：藏於陰影；Stage 3+：清晰可見

### 7.3 紙條三版（F-B-08~10）

詳見 §5.7；三版視覺對應陣營傾向（light = 奧蘿瑞 / dark = 異神 / neutral = 中立）。

### 7.4 Stage 4 場景變化

- 公會場景整體調低飽和度 10%
- 奧菲莉雅相關物件（A-08 椅子、A-09 茶杯）變灰
- 場景說明層（F-B-06）疊加灰字「她沒回來」

### 7.5 Stage 5 終局視覺

- 全螢幕黑底（`#0A0A0A`，避開純黑）
- 白字、極簡襯線體
- 對話框使用 F-B-07 規格
