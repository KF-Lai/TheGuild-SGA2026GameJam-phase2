_建立時間：2026-05-01_

## 0. 文件目的

本檔為 The Guild 所有 UI 元素的單一事實來源（Single Source of Truth）。所有 UI 來源由 26 份 GDD（F-01~F-03、C-01~C-06、FT-01~FT-12、P-01~P-03、D-01~D-02）反向推導，並補充劇本（FT-09 v3.1 奧蘿瑞陣營）所需特殊 UI 與通用控件。

**用途**：

1. UI 製作 / 生成的狀態追蹤（5 階段：Spec → Wireframe → Mockup → Asset → Impl）
2. 跨 GDD UI 需求彙整，避免重複設計與遺漏
3. 為 P-02 Main UI Framework GDD §3 各面板填寫提供範圍依據
4. 為 art-director / character-designer / unity-ui-specialist 提供工項清單

## 1. 命名規則

### 1.1 UI ID 格式

```
{層代碼}-{兩位數} 或 {層代碼}-{子層}-{兩位數}
```

| 層代碼 | 意義 |
|---|---|
| `A-` | Scene 場景層 |
| `B-` | In-Scene UI 場景內嵌 |
| `C-` | Always-on HUD 常駐覆蓋 |
| `D-` | Main Panel 主面板 |
| `E-` | Modal Popup 模態彈窗 |
| `F-A` ~ `F-H` | 原子素材子層 |

範例：`D-01`（委託板）、`E-05`（訃聞畫面）、`F-C-08`（紙條 light 版）

### 1.2 個別 UI Spec 檔命名

```
design/UI/【{UI-ID}】{ui-name}.md
```

例：`design/UI/【D-01】commission-board.md`、`design/UI/【F-C-01】dialogue-bubble-character.md`

### 1.3 UI 美術資產命名

```
Assets/Art/UI/{Category}/{UI-ID}_{variant}.png
```

例：`Assets/Art/UI/Panel/D-01_default.png`、`Assets/Art/UI/Bubble/F-C-08_light.png`

## 2. 狀態圖例（5 階段）

| 階段 | 圖示意義 | 產出形式 | 主負責角色 |
|---|---|---|---|
| **Spec** | UI 個別規格書（互動、版型、狀態機、文案 key 列表） | `design/UI/【{ID}】*.md` | ux-designer |
| **Wireframe** | 低保真線框圖（手繪或 ASCII / 文字版型描述） | 圖檔 / 文字 | ux-designer |
| **Mockup** | 高保真視覺稿（含色彩、字型、構圖） | Midjourney / SD 產圖 | art-director |
| **Asset** | 最終美術素材入庫（atlas、sprite、9-slice） | `Assets/Art/UI/` | art-director / character-designer |
| **Impl** | Unity UI Toolkit (UXML/USS) 實作通過 EditMode/PlayMode 測試 | Unity 場景 + 代碼 | unity-ui-specialist |

| 圖示 | 意義 |
|---|---|
| ✅ | 完成 |
| 🔧 | 進行中 |
| 📐 | 規劃中（已排入工項） |
| ⬜ | 未啟動 |
| ⚠️ | Post-Jam（Jam 範疇外） |
| ➖ | 不適用（如 atomic asset 不需 wireframe） |

## 3. UI 分類框架（六層）

| 層 | 名稱 | 渲染層級 | 是否阻塞輸入 | 範例 |
|---|---|---|---|---|
| **A** | Scene 場景層 | 最底層 | 否（穿透） | 公會橫幅景觀、可互動場景物件 |
| **B** | In-Scene UI | Scene 之上 | 否 | 金幣顯示、破產倒數、頭頂狀態 |
| **C** | Always-on HUD | In-Scene 之上 | 否（局部 hit area） | 設定按鈕、Log 入口、劇情指示器 |
| **D** | Main Panel | HUD 之上 | 部分（panel 內部接收輸入） | 委託板、名冊、建設、面試 |
| **E** | Modal Popup | Main Panel 之上 | 是 | 啟動畫面、訃聞、確認彈窗 |
| **F** | Atomic Asset | 跨層 | — | 圖示、字型、立繪、按鈕、氣泡框 |

**Z-order（由低至高）**：A < B < C < D < E < （F 依 host 容器決定）

## 7. 維護指引

1. **新增 UI 項目**：先在本 index 登記，分配 ID，標記 owner GDD
2. **狀態變更**：完成某階段後立即更新對應圖示，並刷新 §5 統計
3. **個別 Spec 撰寫**：spec 完成後路徑寫入「備註」欄
4. **重大重構**：在 §8 變更歷史登記日期與摘要
5. **避免在此 index 內寫詳細互動規格**：互動細節寫在個別 spec 檔，本 index 僅作為總目錄
